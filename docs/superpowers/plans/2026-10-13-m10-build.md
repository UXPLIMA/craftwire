# M10 Build Tools and Token Diet Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make building through Craftwire cheap and fast: a code-based, file-driven `build` tool with re-runnable parts and
exact undo, an isometric preview in the same call, a building skill, and a hub-wide token diet.

**Architecture:** A new plain-Java module `build-core` holds everything that does not need Minecraft (packed positions,
edit buffers, shapes, transforms, block sources, the `layers` notation, the project layer stack and its storage).
`agent-script` runs build scripts in a sandboxed GraalJS context against `build-core`'s `BuildApi`. `mc-shared` gets
`BuildStates` (vanilla block-state parse/rotate/mirror), and `agent-paper` adds the world adapter (chunk reads, budgeted
fast writes, connection pass), the `build.run` / `build.manage` handlers and the isometric renderer. The hub adds the
`build` / `build_manage` tools, reads build files, extracts block colours from the client jar, compacts all results and
trims tool descriptions to a tested budget.

**Tech Stack:** Java 25 (Gradle, JUnit 5, paperweight-userdev, GraalJS 25.0.4 polyglot), TypeScript (Node, MCP SDK,
zod 4, vitest). No new dependencies.

**Spec:** `docs/superpowers/specs/2026-10-13-m10-build-design.md`

## Global Constraints

- Version 0.10.0 for hub, plugin and mod (`gradle.properties craftwire_version`, `hub/package.json`, `hub/src/version.ts`).
- Minecraft 26.2 and 26.3 (Paper), Folia 26.2. Mojang names. Build locally with `JAVA_HOME="C:/Program Files/Java/jdk-26.0.1"`.
- No new runtime dependencies in the hub or the agents ("own code, no deps"): PNG decoding, zip reading, JSON are ours or built in.
- Full tool list at most 28,000 chars; the `build` profile at most 10,500 chars; no single tool definition over 1,800 chars.
- Tool results are compact JSON (`JSON.stringify(data)`).
- `build` compute: default timeout 60,000 ms, max 300,000 ms. Apply: at most 8 ms of writes per tick per thread.
- Write flags: `Block.UPDATE_CLIENTS | Block.UPDATE_KNOWN_SHAPE | Block.UPDATE_SUPPRESS_DROPS` (2 | 16 | 32, verified with javap in Task 12).
- Config keys (plugins/Craftwire/config.yml): `allow-build` (true), `max-build-volume` (5,000,000), `build-journal-limit-mb` (512).
- Error codes: `SCRIPT_ERROR`, `BAD_BLOCK`, `TOO_LARGE`, `TIMEOUT`, `APPLY_FAILED`, `BAD_ARGUMENT`, `PROJECT_NOT_FOUND`, `PERMISSION_DISABLED`.
- In HTTP mode `file` is refused unless the hub runs with `--build-dir <dir>`; then only paths inside it are read.
- Coordinates in scripts: relative to the project origin; +x east, +y up, +z south; rotation is clockwise seen from above.
- Python on this machine: always `encoding='utf-8'`. Bash heredocs eat backslashes: write code containing `\n` or regex with the Write/Edit tools.

## Review Focus

1. Two parts covering the same position, then removing the lower one: the upper part's block must stay (layer stack), and removing the upper one must bring the lower part's block back, not the original world. Test in Task 9 (`removingUpperPartRevealsLowerPart`).
2. A build run while a player stands inside the area or chunks are unloaded: chunks load asynchronously and writes still happen; no "chunk not loaded" failure. Test in Task 13 (`buildsIntoUnloadedChunks`).
3. A script that loops forever or allocates a huge buffer: the run is cancelled (`TIMEOUT`) or refused (`TOO_LARGE`) and nothing is written. Tests in Task 11 (`infiniteLoopTimesOut`, `tooManyBlocksIsTooLarge`) and Task 4 (`bufferRefusesBeyondLimit`).
4. Server restart between a build and its undo: the project, its parts and the originals load back and `undo`/`clear` restore exactly. Test in Task 13 (`projectSurvivesReload`).
5. Stairs, fences, walls and panes placed by a script connect to their neighbours (corners of hip roofs become outer corners). Test in Task 13 (`connectionPassShapesStairsAndFences`).

// hub/src/tool-policy.ts (additions)
export const TOOL_GROUPS: Record<string, readonly string[]> = {
  hub: ["list_instances", "get_request_status", "wait_for", "logs", "exceptions"],
  client: ["screenshot", "record", "camera", "gui_read", "gui_action", "input", "chat", "hud_read", "player_state", "client_settings"],
  server: ["server_command", "server_eval", "world_query", "world_edit", "world_render", "server_info", "plugin_manage", "events"],
  build: ["build", "build_manage"],
  dev: ["server_process", "plugin_deploy", "client_process", "scenario_run"],
  bots: ["bot_spawn", "bot_action", "bot_remove"],
  debug: ["profile", "trace", "client_eval"],
  extensions: [],
};

export const PROFILES: Record<string, { groups: string[]; tools?: string[] }> = {
  build: { groups: ["hub", "build"], tools: ["world_query", "world_render", "server_command", "screenshot", "camera"] },
};

/** --read-only, --tools <groups> and --profile <name>, shared by the stdio hub and craftwire serve. */
export function parseHubArgs(argv: string[]): { policy?: ToolPolicy } {
  let readOnly = false;
  let groups: Set<string> | undefined;
  let extraTools: Set<string> | undefined;
  for (let i = 0; i < argv.length; i++) {
    const flag = argv[i];
    const value = () => {
      const v = argv[++i];
      if (v === undefined) throw new Error(`${flag} needs a value`);
      return v;
    };
    if (flag === "--read-only") readOnly = true;
    else if (flag === "--tools") groups = new Set([...(groups ?? []), ...parseToolGroups(value())]);
    else if (flag === "--profile") {
      const name = value();
      const p = PROFILES[name];
      if (p === undefined) throw new Error(`Unknown profile ${name} (profiles: ${Object.keys(PROFILES).join(", ")})`);
      groups = new Set([...(groups ?? []), ...p.groups]);
      extraTools = new Set([...(extraTools ?? []), ...(p.tools ?? [])]);
    }
  }
  if (!readOnly && groups === undefined) return {};
  return { policy: new ToolPolicy({ readOnly, ...(groups ? { groups } : {}), ...(extraTools ? { extraTools } : {}) }) };
}
```

In `ToolPolicy.lists`, before the group check: `if (this.o.extraTools?.has(tool)) return this.o.readOnly ? READS.has(tool) || tool in READING_ACTIONS : true;`. Constructor option type gains `extraTools?: Set<string>`.

`cli.ts main()`: `const { policy } = parseHubArgs(process.argv.slice(2));` then `createCraftwireServer({ ...hub.ctx, ...(policy ? { policy } : {}) })`. A parse error writes `craftwire: <message>` to stderr and exits 2. The dispatch `else main()` stays last, so `npx craftwire --profile build` reaches `main`.

`serve-command.ts`: `--profile` handled by delegating flag parsing for `--read-only/--tools/--profile` to `parseHubArgs` (keep its other flags); usage text gains `--profile <name>  a preset of groups and tools: build`.

`setup.ts`: `--profile <name>` validated against `PROFILES`, appended to the args written into each client's config; add a test asserting the written config for `claude-desktop` contains `"--profile","build"`.

// Pos.java
package com.uxplima.craftwire.build;

/** A block position packed in a long, in the same layout as Minecraft's BlockPos.asLong (x 26 bits, z 26, y 12). */
public final class Pos {
    /** x and z stop one short of -2^25, so no position packs to Long.MIN_VALUE (the empty key of LongIntMap). */
    public static final int MIN_XZ = -(1 << 25) + 1;
    public static final int MAX_XZ = (1 << 25) - 1;
    public static final int MIN_Y = -2048;
    public static final int MAX_Y = 2047;

    private Pos() {}

    public static long pack(int x, int y, int z) {
        return ((long) (x & 0x3FFFFFF) << 38) | ((long) (z & 0x3FFFFFF) << 12) | (y & 0xFFFL);
    }

    public static int x(long p) {
        return (int) (p >> 38);
    }

    public static int y(long p) {
        return (int) (p << 52 >> 52);
    }

    public static int z(long p) {
        return (int) (p << 26 >> 38);
    }

    public static boolean inRange(int x, int y, int z) {
        return x >= MIN_XZ && x <= MAX_XZ && z >= MIN_XZ && z <= MAX_XZ && y >= MIN_Y && y <= MAX_Y;
    }
}

// LongIntMap.java
package com.uxplima.craftwire.build;

import java.util.Arrays;

/** Positions to state ids: open addressing, about 12 bytes per entry. Values are never negative. */
public final class LongIntMap {
    public static final int NONE = -1;
    private static final long EMPTY = Long.MIN_VALUE;
    private static final float LOAD = 0.6f;

    @FunctionalInterface
    public interface Entry {
        void accept(long key, int value);
    }

    private long[] keys;
    private int[] values;
    private int size;
    private int mask;

    public LongIntMap() {
        this(16);
    }

    public LongIntMap(int expected) {
        int cap = Integer.highestOneBit(Math.max(4, (int) (expected / LOAD)) - 1) << 1;
        alloc(cap);
    }

    private void alloc(int capacity) {
        keys = new long[capacity];
        Arrays.fill(keys, EMPTY);
        values = new int[capacity];
        mask = capacity - 1;
    }

    private static int hash(long k) {
        k ^= k >>> 33;
        k *= 0xff51afd7ed558ccdL;
        k ^= k >>> 33;
        return (int) k;
    }

    public int get(long key) {
        for (int i = hash(key) & mask; ; i = (i + 1) & mask) {
            long k = keys[i];
            if (k == EMPTY) return NONE;
            if (k == key) return values[i];
        }
    }

    public boolean containsKey(long key) {
        return get(key) != NONE;
    }

    /** Sets the value and returns the previous one, or NONE. */
    public int put(long key, int value) {
        if (key == EMPTY) throw new IllegalArgumentException("Position out of range");
        if (value < 0) throw new IllegalArgumentException("Negative value " + value);
        if (size + 1 > keys.length * LOAD) grow();
        for (int i = hash(key) & mask; ; i = (i + 1) & mask) {
            long k = keys[i];
            if (k == EMPTY) {
                keys[i] = key;
                values[i] = value;
                size++;
                return NONE;
            }
            if (k == key) {
                int old = values[i];
                values[i] = value;
                return old;
            }
        }
    }

    public int size() {
        return size;
    }

    public void forEach(Entry e) {
        for (int i = 0; i < keys.length; i++) {
            if (keys[i] != EMPTY) e.accept(keys[i], values[i]);
        }
    }

    public LongIntMap copy() {
        LongIntMap c = new LongIntMap(4);
        c.keys = keys.clone();
        c.values = values.clone();
        c.size = size;
        c.mask = mask;
        return c;
    }

    private void grow() {
        long[] oldKeys = keys;
        int[] oldValues = values;
        alloc(keys.length * 2);
        size = 0;
        for (int i = 0; i < oldKeys.length; i++) {
            if (oldKeys[i] != EMPTY) put(oldKeys[i], oldValues[i]);
        }
    }
}

package com.uxplima.craftwire.build;

/** The blocks one part places, in world coordinates; a later placement at the same position wins. */
public final class EditBuffer {
    private final LongIntMap blocks = new LongIntMap(1024);
    private final long limit;
    private int minX = Integer.MAX_VALUE, minY = Integer.MAX_VALUE, minZ = Integer.MAX_VALUE;
    private int maxX = Integer.MIN_VALUE, maxY = Integer.MIN_VALUE, maxZ = Integer.MIN_VALUE;
    private int outOfRange;

    public EditBuffer(long limit) {
        this.limit = limit;
    }

    public void put(int x, int y, int z, int state) {
        if (!Pos.inRange(x, y, z)) {
            outOfRange++;
            return;
        }
        if (blocks.put(Pos.pack(x, y, z), state) != LongIntMap.NONE) return;
        if (blocks.size() > limit) {
            throw new BuildError("TOO_LARGE", "The part places more than " + limit + " blocks",
                    "Split it into smaller parts, or raise max-build-volume in plugins/Craftwire/config.yml.");
        }
        minX = Math.min(minX, x); minY = Math.min(minY, y); minZ = Math.min(minZ, z);
        maxX = Math.max(maxX, x); maxY = Math.max(maxY, y); maxZ = Math.max(maxZ, z);
    }

    public int get(int x, int y, int z) {
        return Pos.inRange(x, y, z) ? blocks.get(Pos.pack(x, y, z)) : LongIntMap.NONE;
    }

    public LongIntMap blocks() {
        return blocks;
    }

    public int size() {
        return blocks.size();
    }

    /** {minX, minY, minZ, maxX, maxY, maxZ}, or null when nothing was placed. */
    public int[] bbox() {
        return blocks.size() == 0 ? null : new int[] {minX, minY, minZ, maxX, maxY, maxZ};
    }

    /** Placements dropped because they were outside the packable range. */
    public int outOfRange() {
        return outOfRange;
    }
}

// Transform.java
package com.uxplima.craftwire.build;

/**
 * A frame: world = offset + rotate(mirror(local)). rot is clockwise quarter turns seen from above
 * ((x, z) -> (-z, x) per turn); mirrorX negates x before turning. A Z mirror is mirrorX plus two turns.
 */
public record Transform(int ox, int oy, int oz, int rot, boolean mirrorX) {
    public static final Transform IDENTITY = new Transform(0, 0, 0, 0, false);

    /** A frame from script arguments; mirror is "", "x" or "z". */
    public static Transform of(int dx, int dy, int dz, int quarterTurns, String mirror) {
        int q = Math.floorMod(quarterTurns, 4);
        return switch (mirror) {
            case "" -> new Transform(dx, dy, dz, q, false);
            case "x" -> new Transform(dx, dy, dz, q, true);
            case "z" -> new Transform(dx, dy, dz, (q + 2) & 3, true);
            default -> throw new IllegalArgumentException("mirror must be 'x' or 'z', not '" + mirror + "'");
        };
    }

    public int worldX(int x, int z) {
        int mx = mirrorX ? -x : x;
        return ox + switch (rot) {
            case 0 -> mx;
            case 1 -> -z;
            case 2 -> -mx;
            default -> z;
        };
    }

    public int worldY(int y) {
        return oy + y;
    }

    public int worldZ(int x, int z) {
        int mx = mirrorX ? -x : x;
        return oz + switch (rot) {
            case 0 -> z;
            case 1 -> mx;
            case 2 -> -z;
            default -> -mx;
        };
    }

    /** The state as it looks in this frame: mirrored first, then turned. */
    public int state(int id, StatePalette p) {
        int s = mirrorX ? p.mirror(id, Axis.X) : id;
        return rot == 0 ? s : p.rotate(s, rot);
    }

    /** The frame of child placed inside this one. */
    public Transform then(Transform child) {
        int r = Math.floorMod(rot + (mirrorX ? -child.rot : child.rot), 4);
        return new Transform(worldX(child.ox, child.oz), worldY(child.oy), worldZ(child.ox, child.oz), r, mirrorX ^ child.mirrorX);
    }
}

// Picks.java
package com.uxplima.craftwire.build;

/** Block sources. Random choices hash the position and the seed, so a re-run picks the same blocks. */
public final class Picks {
    private Picks() {}

    public static BlockPick of(int state) {
        return (x, y, z) -> state;
    }

    public static BlockPick mix(int[] states, int[] weights, long seed) {
        if (states.length == 0 || states.length != weights.length) throw new IllegalArgumentException("mix needs one weight per block");
        int[] cumulative = new int[weights.length];
        int total = 0;
        for (int i = 0; i < weights.length; i++) {
            if (weights[i] < 0) throw new IllegalArgumentException("mix weights cannot be negative");
            total += weights[i];
            cumulative[i] = total;
        }
        if (total == 0) throw new IllegalArgumentException("mix weights add up to 0");
        int sum = total;
        return (x, y, z) -> {
            int r = (int) Math.floorMod(hash(x, y, z, seed), (long) sum);
            for (int i = 0; i < cumulative.length; i++) if (r < cumulative[i]) return states[i];
            return states[states.length - 1];
        };
    }

    /** Blocks in order from `from` to `to` along axis, with a little dither where bands meet. */
    public static BlockPick gradient(char axis, int from, int to, int[] states, long seed) {
        if (states.length == 0) throw new IllegalArgumentException("gradient needs at least one block");
        int n = states.length;
        double span = Math.max(1, to - from);
        return (x, y, z) -> {
            int c = axis == 'x' ? x : axis == 'z' ? z : y;
            double t = (c - from) / span;
            double jitter = (unit(hash(x, y, z, seed ^ 0x5DEECE66DL)) - 0.5) / n;
            int i = (int) Math.floor((t + jitter) * n);
            return states[Math.max(0, Math.min(n - 1, i))];
        };
    }

    public static long hash(int x, int y, int z, long seed) {
        long h = seed ^ (x * 0x9E3779B97F4A7C15L) ^ (y * 0xC2B2AE3D27D4EB4FL) ^ (z * 0x165667B19E3779F9L);
        h ^= h >>> 31;
        h *= 0xBF58476D1CE4E5B9L;
        h ^= h >>> 29;
        h *= 0x94D049BB133111EBL;
        return h ^ (h >>> 32);
    }

    static double unit(long h) {
        return (h >>> 11) * 0x1.0p-53;
    }
}

// Shapes.java
package com.uxplima.craftwire.build;

/** Shapes in the caller's frame. Boxes are inclusive and take their corners in any order. */
public final class Shapes {
    private Shapes() {}

    public static void fill(Placer p, int x1, int y1, int z1, int x2, int y2, int z2, BlockPick b) {
        for (int y = Math.min(y1, y2); y <= Math.max(y1, y2); y++)
            for (int z = Math.min(z1, z2); z <= Math.max(z1, z2); z++)
                for (int x = Math.min(x1, x2); x <= Math.max(x1, x2); x++) p.place(x, y, z, b);
    }

    /** Walls, floor and ceiling of b; everything inside becomes air (a room). */
    public static void hollow(Placer p, int x1, int y1, int z1, int x2, int y2, int z2, BlockPick b, int air, boolean floor, boolean ceiling) {
        int ax = Math.min(x1, x2), bx = Math.max(x1, x2), ay = Math.min(y1, y2), by = Math.max(y1, y2), az = Math.min(z1, z2), bz = Math.max(z1, z2);
        BlockPick empty = Picks.of(air);
        for (int y = ay; y <= by; y++)
            for (int z = az; z <= bz; z++)
                for (int x = ax; x <= bx; x++) {
                    boolean side = x == ax || x == bx || z == az || z == bz;
                    boolean shell = side || (y == ay && floor) || (y == by && ceiling);
                    p.place(x, y, z, shell ? b : empty);
                }
    }

    public static void walls(Placer p, int x1, int y1, int z1, int x2, int y2, int z2, BlockPick b) {
        int ax = Math.min(x1, x2), bx = Math.max(x1, x2), az = Math.min(z1, z2), bz = Math.max(z1, z2);
        for (int y = Math.min(y1, y2); y <= Math.max(y1, y2); y++)
            for (int z = az; z <= bz; z++)
                for (int x = ax; x <= bx; x++) if (x == ax || x == bx || z == az || z == bz) p.place(x, y, z, b);
    }

    public static void outline(Placer p, int x1, int y1, int z1, int x2, int y2, int z2, BlockPick b) {
        int ax = Math.min(x1, x2), bx = Math.max(x1, x2), ay = Math.min(y1, y2), by = Math.max(y1, y2), az = Math.min(z1, z2), bz = Math.max(z1, z2);
        for (int y = ay; y <= by; y++)
            for (int z = az; z <= bz; z++)
                for (int x = ax; x <= bx; x++) {
                    int planes = (x == ax || x == bx ? 1 : 0) + (y == ay || y == by ? 1 : 0) + (z == az || z == bz ? 1 : 0);
                    if (planes >= 2) p.place(x, y, z, b);
                }
    }

    /** half: 0 whole, 1 top half (y >= cy), -1 bottom half. */
    public static void sphere(Placer p, int cx, int cy, int cz, int r, BlockPick b, boolean hollow, int half) {
        ellipsoidImpl(p, cx, cy, cz, r, r, r, b, hollow, half);
    }

    public static void ellipsoid(Placer p, int cx, int cy, int cz, int rx, int ry, int rz, BlockPick b, boolean hollow) {
        ellipsoidImpl(p, cx, cy, cz, rx, ry, rz, b, hollow, 0);
    }

    private static boolean inEllipsoid(int dx, int dy, int dz, double rx, double ry, double rz) {
        double a = dx / rx, c = dy / ry, e = dz / rz;
        return a * a + c * c + e * e < 1.0;
    }

    private static void ellipsoidImpl(Placer p, int cx, int cy, int cz, int rx, int ry, int rz, BlockPick b, boolean hollow, int half) {
        double ex = rx + 0.5, ey = ry + 0.5, ez = rz + 0.5;
        for (int dy = -ry; dy <= ry; dy++) {
            if (half > 0 && dy < 0 || half < 0 && dy > 0) continue;
            for (int dz = -rz; dz <= rz; dz++)
                for (int dx = -rx; dx <= rx; dx++) {
                    if (!inEllipsoid(dx, dy, dz, ex, ey, ez)) continue;
                    if (hollow && inEllipsoid(dx + 1, dy, dz, ex, ey, ez) && inEllipsoid(dx - 1, dy, dz, ex, ey, ez)
                            && inEllipsoid(dx, dy + 1, dz, ex, ey, ez) && inEllipsoid(dx, dy - 1, dz, ex, ey, ez)
                            && inEllipsoid(dx, dy, dz + 1, ex, ey, ez) && inEllipsoid(dx, dy, dz - 1, ex, ey, ez)) continue;
                    p.place(cx + dx, cy + dy, cz + dz, b);
                }
        }
    }

    private static boolean inDisk(int a, int c, double r) {
        return a * a + c * c < (r + 0.5) * (r + 0.5);
    }

    /** A cylinder of h blocks from (cx, y, cz) along axis 'y' (up), 'x' (east) or 'z' (south). */
    public static void cylinder(Placer p, int cx, int y, int cz, int r, int h, BlockPick b, boolean hollow, char axis) {
        for (int i = 0; i < h; i++)
            for (int c = -r; c <= r; c++)
                for (int a = -r; a <= r; a++) {
                    if (!inDisk(a, c, r)) continue;
                    if (hollow && inDisk(a + 1, c, r) && inDisk(a - 1, c, r) && inDisk(a, c + 1, r) && inDisk(a, c - 1, r)) continue;
                    switch (axis) {
                        case 'x' -> p.place(cx + i, y + a, cz + c, b);
                        case 'z' -> p.place(cx + a, y + c, cz + i, b);
                        default -> p.place(cx + a, y + i, cz + c, b);
                    }
                }
    }

    public static void cone(Placer p, int cx, int y, int cz, int r, int h, BlockPick b, boolean hollow) {
        for (int i = 0; i < h; i++) {
            double ri = r * (1.0 - (double) i / h);
            int ir = (int) Math.ceil(ri);
            for (int c = -ir; c <= ir; c++)
                for (int a = -ir; a <= ir; a++) {
                    if (!inDisk(a, c, ri)) continue;
                    if (hollow && i < h - 1 && inDisk(a + 1, c, ri) && inDisk(a - 1, c, ri) && inDisk(a, c + 1, ri) && inDisk(a, c - 1, ri)) continue;
                    p.place(cx + a, y + i, cz + c, b);
                }
        }
    }

    /** A straight line; width w makes it a w x w x w brush. */
    public static void line(Placer p, int x1, int y1, int z1, int x2, int y2, int z2, BlockPick b, int width) {
        int n = Math.max(Math.abs(x2 - x1), Math.max(Math.abs(y2 - y1), Math.abs(z2 - z1)));
        int lo = -(width - 1) / 2, hi = width / 2;
        for (int i = 0; i <= n; i++) {
            double t = n == 0 ? 0 : (double) i / n;
            int x = (int) Math.round(x1 + (x2 - x1) * t), y = (int) Math.round(y1 + (y2 - y1) * t), z = (int) Math.round(z1 + (z2 - z1) * t);
            for (int dy = lo; dy <= hi; dy++)
                for (int dz = lo; dz <= hi; dz++)
                    for (int dx = lo; dx <= hi; dx++) p.place(x + dx, y + dy, z + dz, b);
        }
    }

    /** A half-ellipse arch from (x1, z1) to (x2, z2) on one axis, rising `height` above y, `thickness` blocks deep downward. */
    public static void arch(Placer p, int x1, int y, int z1, int x2, int z2, int height, BlockPick b, int thickness) {
        if (x1 != x2 && z1 != z2) throw new IllegalArgumentException("An arch runs along x or along z: give equal x or equal z");
        boolean alongX = z1 == z2;
        int a0 = alongX ? Math.min(x1, x2) : Math.min(z1, z2), a1 = alongX ? Math.max(x1, x2) : Math.max(z1, z2);
        double mid = (a0 + a1) / 2.0, half = (a1 - a0) / 2.0 + 0.5;
        for (int a = a0; a <= a1; a++) {
            double u = (a - mid) / half;
            int top = y + (int) Math.round(height * Math.sqrt(Math.max(0, 1 - u * u)));
            for (int yy = Math.max(y, top - thickness + 1); yy <= top; yy++) {
                if (alongX) p.place(a, yy, z1, b);
                else p.place(x1, yy, a, b);
            }
        }
    }

    /** A prism over the polygon (xs[i], zs[i]) from y, h blocks high; hollow keeps only the edges. */
    public static void polygon(Placer p, int[] xs, int[] zs, int y, int h, BlockPick b, boolean hollow) {
        if (xs.length < 3 || xs.length != zs.length) throw new IllegalArgumentException("A polygon needs at least 3 points [x, z]");
        for (int level = y; level < y + h; level++) {
            if (hollow) {
                for (int i = 0; i < xs.length; i++) {
                    int j = (i + 1) % xs.length;
                    line(p, xs[i], level, zs[i], xs[j], level, zs[j], b, 1);
                }
                continue;
            }
            int minX = Integer.MAX_VALUE, maxX = Integer.MIN_VALUE, minZ = Integer.MAX_VALUE, maxZ = Integer.MIN_VALUE;
            for (int i = 0; i < xs.length; i++) {
                minX = Math.min(minX, xs[i]); maxX = Math.max(maxX, xs[i]); minZ = Math.min(minZ, zs[i]); maxZ = Math.max(maxZ, zs[i]);
            }
            for (int z = minZ; z <= maxZ; z++)
                for (int x = minX; x <= maxX; x++) if (inside(xs, zs, x + 0.5, z + 0.5)) p.place(x, level, z, b);
        }
    }

    private static boolean inside(int[] xs, int[] zs, double px, double pz) {
        boolean in = false;
        for (int i = 0, j = xs.length - 1; i < xs.length; j = i++) {
            if ((zs[i] > pz) != (zs[j] > pz) && px < (double) (xs[j] - xs[i]) * (pz - zs[i]) / (zs[j] - zs[i]) + xs[i]) in = !in;
        }
        return in;
    }
}

package com.uxplima.craftwire.build;

/**
 * Roofs from stairs and slabs. A stair's facing is its high side, so a slope rising toward the south uses facing=south.
 * Corners of hip roofs are straight stairs here; the server's connection pass turns them into outer corners.
 */
public final class Roofs {
    private Roofs() {}

    public record Spec(int x1, int z1, int x2, int z2, int y, String type, String axis, int overhang, String stairs, String slab,
                       BlockPick fill, String facing) {}

    public static void roof(Placer p, StatePalette pal, Spec s) {
        int o = Math.max(0, s.overhang());
        int bx1 = Math.min(s.x1(), s.x2()) - o, bx2 = Math.max(s.x1(), s.x2()) + o;
        int bz1 = Math.min(s.z1(), s.z2()) - o, bz2 = Math.max(s.z1(), s.z2()) + o;
        String slabId = s.slab().isEmpty() ? s.stairs().replace("_stairs", "_slab") : s.slab();
        BlockPick slab = Picks.of(pal.id(slabId + "[type=bottom]"));
        switch (s.type()) {
            case "gable" -> {
                String axis = s.axis().isEmpty() ? (bx2 - bx1 >= bz2 - bz1 ? "x" : "z") : s.axis();
                gable(p, pal, s, bx1, bz1, bx2, bz2, axis.equals("x"), slab);
            }
            case "hip" -> hip(p, pal, s, bx1, bz1, bx2, bz2, slab);
            case "shed" -> shed(p, pal, s, bx1, bz1, bx2, bz2);
            case "flat" -> Shapes.fill(p, bx1, s.y(), bz1, bx2, s.y(), bz2, slab);
            default -> throw new IllegalArgumentException("roof type must be gable, hip, shed or flat, not '" + s.type() + "'");
        }
    }

    private static BlockPick stair(StatePalette pal, String stairs, String facing) {
        return Picks.of(pal.id(stairs + "[facing=" + facing + ",half=bottom]"));
    }

    private static void gable(Placer p, StatePalette pal, Spec s, int bx1, int bz1, int bx2, int bz2, boolean ridgeAlongX, BlockPick slab) {
        // Work in (along, across): along follows the ridge, across rises from both sides toward it.
        int a1 = ridgeAlongX ? bx1 : bz1, a2 = ridgeAlongX ? bx2 : bz2, c1 = ridgeAlongX ? bz1 : bx1, c2 = ridgeAlongX ? bz2 : bx2;
        int end1 = ridgeAlongX ? Math.min(s.x1(), s.x2()) : Math.min(s.z1(), s.z2());
        int end2 = ridgeAlongX ? Math.max(s.x1(), s.x2()) : Math.max(s.z1(), s.z2());
        BlockPick low = stair(pal, s.stairs(), ridgeAlongX ? "south" : "east");
        BlockPick high = stair(pal, s.stairs(), ridgeAlongX ? "north" : "west");
        for (int i = 0; ; i++) {
            int n = c1 + i, f = c2 - i, yy = s.y() + i;
            if (n > f) break;
            for (int a = a1; a <= a2; a++) {
                if (n == f) put(p, ridgeAlongX, a, yy, n, slab);
                else {
                    put(p, ridgeAlongX, a, yy, n, low);
                    put(p, ridgeAlongX, a, yy, f, high);
                }
            }
            if (s.fill() != null) {
                for (int c = n + 1; c < f; c++) {
                    put(p, ridgeAlongX, end1, yy, c, s.fill());
                    put(p, ridgeAlongX, end2, yy, c, s.fill());
                }
            }
            if (n == f) break;
        }
    }

    private static void put(Placer p, boolean alongX, int along, int y, int across, BlockPick b) {
        if (alongX) p.place(along, y, across, b);
        else p.place(across, y, along, b);
    }

    private static void hip(Placer p, StatePalette pal, Spec s, int bx1, int bz1, int bx2, int bz2, BlockPick slab) {
        BlockPick north = stair(pal, s.stairs(), "south"), south = stair(pal, s.stairs(), "north");
        BlockPick west = stair(pal, s.stairs(), "east"), east = stair(pal, s.stairs(), "west");
        for (int i = 0; ; i++) {
            int x1 = bx1 + i, x2 = bx2 - i, z1 = bz1 + i, z2 = bz2 - i, yy = s.y() + i;
            if (x1 > x2 || z1 > z2) break;
            if (x1 == x2 || z1 == z2) {
                Shapes.fill(p, x1, yy, z1, x2, yy, z2, slab);
                break;
            }
            for (int x = x1; x <= x2; x++) {
                p.place(x, yy, z1, north);
                p.place(x, yy, z2, south);
            }
            for (int z = z1 + 1; z < z2; z++) {
                p.place(x1, yy, z, west);
                p.place(x2, yy, z, east);
            }
        }
    }

    private static void shed(Placer p, StatePalette pal, Spec s, int bx1, int bz1, int bx2, int bz2) {
        BlockPick b = stair(pal, s.stairs(), s.facing());
        boolean alongZ = s.facing().equals("north") || s.facing().equals("south");
        int lo = alongZ ? bz1 : bx1, hi = alongZ ? bz2 : bx2;
        boolean towardLow = s.facing().equals("north") || s.facing().equals("west");
        for (int i = 0; i <= hi - lo; i++) {
            int c = towardLow ? hi - i : lo + i, yy = s.y() + i;
            if (alongZ) for (int x = bx1; x <= bx2; x++) p.place(x, yy, c, b);
            else for (int z = bz1; z <= bz2; z++) p.place(c, yy, z, b);
            if (s.fill() != null) {
                for (int y = s.y(); y < yy; y++) {
                    if (alongZ) {
                        p.place(Math.min(s.x1(), s.x2()), y, c, s.fill());
                        p.place(Math.max(s.x1(), s.x2()), y, c, s.fill());
                    } else {
                        p.place(c, y, Math.min(s.z1(), s.z2()), s.fill());
                        p.place(c, y, Math.max(s.z1(), s.z2()), s.fill());
                    }
                }
            }
        }
    }

    /** A straight staircase climbing toward dir, `width` wide to the right of dir. */
    public static void stairs(Placer p, StatePalette pal, int x, int y, int z, String dir, int length, String stairs, int width) {
        int[] f = switch (dir) {
            case "north" -> new int[] {0, -1};
            case "south" -> new int[] {0, 1};
            case "east" -> new int[] {1, 0};
            case "west" -> new int[] {-1, 0};
            default -> throw new IllegalArgumentException("dir must be north, south, east or west, not '" + dir + "'");
        };
        int rx = -f[1], rz = f[0];   // to the right: north -> east, east -> south
        BlockPick b = stair(pal, stairs, dir);
        for (int i = 0; i < length; i++)
            for (int w = 0; w < width; w++) p.place(x + f[0] * i + rx * w, y + i, z + f[1] * i + rz * w, b);
    }
}

// Layers.java
package com.uxplima.craftwire.build;

import java.util.ArrayList;
import java.util.LinkedHashMap;
import java.util.List;
import java.util.Map;
import java.util.function.IntFunction;

/**
 * One letter per block, one string per height (bottom first), rows north to south separated by '/' or newlines,
 * letters west to east. '.' is air, '~' leaves a position untouched (input), '?' marks an unloaded chunk (output).
 * world_query encoding:'layers' writes it and the layers() script function reads it, so a read region pastes back.
 */
public final class Layers {
    public static final int NOT_LOADED = -2;
    private static final String LETTERS = "abcdefghijklmnopqrstuvwxyzABCDEFGHIJKLMNOPQRSTUVWXYZ0123456789!#$%&*+-:;<=>@^_|";

    public record Encoded(Map<String, String> legend, List<String> layers) {}

    @FunctionalInterface
    public interface StateAt {
        int at(int dx, int dy, int dz);
    }

    private Layers() {}

    public static void place(Placer p, int x, int y, int z, Map<Character, BlockPick> legend, String[] layers, int air) {
        BlockPick empty = Picks.of(air);
        for (int li = 0; li < layers.length; li++) {
            int row = 0;
            for (String raw : layers[li].split("[/\\n]", -1)) {
                String r = raw.strip();
                if (r.isEmpty()) continue;
                for (int col = 0; col < r.length(); col++) {
                    char c = r.charAt(col);
                    if (c == '~') continue;
                    BlockPick b = c == '.' ? empty : legend.get(c);
                    if (b == null) {
                        throw new IllegalArgumentException("Unknown letter '" + c + "' in layer " + li + ", row " + row + ", column " + col
                                + " (legend: " + legend.keySet() + ", '.' air, '~' untouched)");
                    }
                    p.place(x + col, y + li, z + row, b);
                }
                row++;
            }
        }
    }

    public static Encoded encode(int sx, int sy, int sz, StateAt at, IntFunction<String> nameOf, int air) {
        Map<Integer, Character> letters = new LinkedHashMap<>();
        Map<String, String> legend = new LinkedHashMap<>();
        List<String> out = new ArrayList<>(sy);
        StringBuilder b = new StringBuilder(sx * sz + sz);
        for (int dy = 0; dy < sy; dy++) {
            b.setLength(0);
            for (int dz = 0; dz < sz; dz++) {
                if (dz > 0) b.append('/');
                for (int dx = 0; dx < sx; dx++) {
                    int s = at.at(dx, dy, dz);
                    if (s == NOT_LOADED) b.append('?');
                    else if (s == air) b.append('.');
                    else b.append(letters.computeIfAbsent(s, id -> {
                        if (letters.size() >= LETTERS.length()) {
                            throw new BuildError("TOO_MANY_STATES", "The region holds more than " + LETTERS.length() + " different block states",
                                    "Query a smaller region, or use encoding:'runs'.");
                        }
                        char c = LETTERS.charAt(letters.size());
                        legend.put(String.valueOf(c), nameOf.apply(id));
                        return c;
                    }));
                }
            }
            out.add(b.toString());
        }
        return new Encoded(legend, out);
    }
}

package com.uxplima.craftwire.build;

import java.util.HashMap;
import java.util.Map;

/** What a stage wants the world to become: position -> state, and how many of those go back to the original. */
public final class Changes {
    private final LongIntMap targets = new LongIntMap(256);
    private int removed;

    void put(long pos, int state, boolean backToOriginal) {
        targets.put(pos, state);
        if (backToOriginal) removed++;
    }

    public LongIntMap targets() {
        return targets;
    }

    public int size() {
        return targets.size();
    }

    public int removed() {
        return removed;
    }

    public static long chunkKey(int cx, int cz) {
        return (long) cx << 32 | (cz & 0xFFFFFFFFL);
    }

    public Map<Long, long[]> byChunk() {
        Map<Long, int[]> counts = new HashMap<>();
        targets.forEach((pos, s) -> counts.computeIfAbsent(chunkKey(Pos.x(pos) >> 4, Pos.z(pos) >> 4), k -> new int[1])[0]++);
        Map<Long, long[]> out = new HashMap<>();
        Map<Long, int[]> fill = new HashMap<>();
        counts.forEach((k, n) -> {
            out.put(k, new long[n[0]]);
            fill.put(k, new int[1]);
        });
        targets.forEach((pos, s) -> {
            long k = chunkKey(Pos.x(pos) >> 4, Pos.z(pos) >> 4);
            out.get(k)[fill.get(k)[0]++] = pos;
        });
        return out;
    }
}

// Project.java
package com.uxplima.craftwire.build;

import java.util.ArrayDeque;
import java.util.ArrayList;
import java.util.Deque;
import java.util.HashMap;
import java.util.List;
import java.util.Map;

/**
 * A named build: parts stacked in the order they were first run (a later part covers an earlier one), and under them
 * the world as it was before the project touched each position. A position shows its topmost part, else the original.
 */
public final class Project {
    public record Source(String code, String file) {}

    public record History(long seq, String part, LongIntMap previous, Source previousSource) {}

    private final String name;
    private final String world;
    private Transform frame;
    private final List<String> order = new ArrayList<>();
    private final Map<String, LongIntMap> parts = new HashMap<>();
    private final Map<String, Source> sources = new HashMap<>();
    private final LongIntMap original = new LongIntMap(1024);
    private final Deque<History> history = new ArrayDeque<>();
    private long nextSeq = 1;

    public Project(String name, String world, Transform frame) {
        this.name = name;
        this.world = world;
        this.frame = frame;
    }

    public String name() { return name; }
    public String world() { return world; }
    public synchronized Transform frame() { return frame; }
    public synchronized void setFrame(Transform t) { frame = t; }
    public synchronized List<String> parts() { return List.copyOf(order); }
    public synchronized LongIntMap part(String part) { return parts.get(part); }
    public synchronized Source source(String part) { return sources.get(part); }
    public LongIntMap original() { return original; }
    public Deque<History> history() { return history; }

    /** The state shown at pos if `part` held `replacement` (null = the part is gone); NONE when nothing is known. */
    private int visible(long pos, String part, LongIntMap replacement) {
        boolean listed = order.contains(part);
        if (!listed && replacement != null) {
            int s = replacement.get(pos);
            if (s != LongIntMap.NONE) return s;
        }
        for (int i = order.size() - 1; i >= 0; i--) {
            String n = order.get(i);
            LongIntMap m = n.equals(part) ? replacement : parts.get(n);
            if (m == null) continue;
            int s = m.get(pos);
            if (s != LongIntMap.NONE) return s;
        }
        return original.get(pos);
    }

    private boolean covered(long pos, String part, LongIntMap replacement) {
        if (replacement != null && replacement.containsKey(pos)) return true;
        for (String n : order) {
            if (n.equals(part)) continue;
            LongIntMap m = parts.get(n);
            if (m != null && m.containsKey(pos)) return true;
        }
        return false;
    }

    /** What changes in the world if `part` becomes `next` (null removes it). Nothing is committed. */
    public synchronized Changes stage(String part, LongIntMap next) {
        LongIntMap prev = parts.get(part);
        Changes c = new Changes();
        if (prev != null) prev.forEach((pos, s) -> consider(c, pos, part, prev, next));
        if (next != null) next.forEach((pos, s) -> {
            if (prev == null || !prev.containsKey(pos)) consider(c, pos, part, prev, next);
        });
        return c;
    }

    private void consider(Changes c, long pos, String part, LongIntMap prev, LongIntMap next) {
        int before = visible(pos, part, prev);
        int after = visible(pos, part, next);
        if (after == LongIntMap.NONE) return;   // goes back to a world we never changed
        if (before == after && before != LongIntMap.NONE && original.containsKey(pos)) return;
        c.put(pos, after, !covered(pos, part, next));
    }

    /** Makes `next` the part (null removes it) once its changes are in the world. */
    public synchronized void commit(String part, LongIntMap next, Source source, boolean record) {
        LongIntMap prev = parts.get(part);
        if (record) history.push(new History(nextSeq++, part, prev, sources.get(part)));
        if (next == null) {
            parts.remove(part);
            sources.remove(part);
            order.remove(part);
            return;
        }
        if (!parts.containsKey(part)) order.add(part);
        parts.put(part, next);
        if (source != null) sources.put(part, source);
    }

    public synchronized History popHistory() {
        return history.poll();
    }

    /** Every position the project changed, back to its original. */
    public synchronized Changes clearAll() {
        Changes c = new Changes();
        LongIntMap seen = new LongIntMap(1024);
        for (LongIntMap m : parts.values()) {
            m.forEach((pos, s) -> {
                if (seen.put(pos, 0) != LongIntMap.NONE) return;
                int o = original.get(pos);
                if (o != LongIntMap.NONE) c.put(pos, o, true);
            });
        }
        return c;
    }

    /** Forgets parts, history and originals (after clearAll was applied, or on commit). */
    public synchronized void reset() {
        parts.clear();
        sources.clear();
        order.clear();
        history.clear();
    }

    public synchronized void recordOriginal(long pos, int state) {
        if (!original.containsKey(pos)) original.put(pos, state);
    }

    public synchronized int originalOf(long pos) {
        return original.get(pos);
    }

    /** For the store: restores history in order (oldest first) and the sequence counter. */
    synchronized void restoreHistory(List<History> oldestFirst) {
        history.clear();
        for (History h : oldestFirst) {
            history.push(h);
            nextSeq = Math.max(nextSeq, h.seq() + 1);
        }
    }

    /** For the store: puts a part back as loaded. */
    synchronized void restorePart(String part, LongIntMap blocks, Source source) {
        if (!parts.containsKey(part)) order.add(part);
        parts.put(part, blocks);
        if (source != null) sources.put(part, source);
    }
}

// ProjectStore.java
package com.uxplima.craftwire.build;

import com.google.gson.Gson;
import com.google.gson.JsonArray;
import com.google.gson.JsonObject;
import java.io.BufferedInputStream;
import java.io.BufferedOutputStream;
import java.io.DataInputStream;
import java.io.DataOutputStream;
import java.io.IOException;
import java.io.UncheckedIOException;
import java.nio.charset.StandardCharsets;
import java.nio.file.Files;
import java.nio.file.Path;
import java.nio.file.StandardCopyOption;
import java.util.ArrayList;
import java.util.Comparator;
import java.util.HashMap;
import java.util.List;
import java.util.Map;
import java.util.stream.Stream;
import java.util.zip.DeflaterOutputStream;
import java.util.zip.InflaterInputStream;

/**
 * Projects on disk, so undo and clear survive a restart. Block maps are deflated (magic, state names, then position +
 * name index per entry); states are stored by name because numeric ids change between versions.
 */
public final class ProjectStore {
    private static final int MAGIC = 0x43574231;   // "CWB1"
    private static final Gson GSON = new Gson();

    private final Path root;
    private final StatePalette palette;
    private final List<String> warnings = new ArrayList<>();

    public ProjectStore(Path root, StatePalette palette) {
        this.root = root;
        this.palette = palette;
    }

    public List<String> warnings() {
        return List.copyOf(warnings);
    }

    public synchronized void save(Project p) throws IOException {
        Path dir = root.resolve(p.name());
        Files.createDirectories(dir.resolve("parts"));
        Files.createDirectories(dir.resolve("history"));
        JsonObject j = new JsonObject();
        j.addProperty("name", p.name());
        j.addProperty("world", p.world());
        Transform f = p.frame();
        JsonArray frame = new JsonArray();
        frame.add(f.ox()); frame.add(f.oy()); frame.add(f.oz()); frame.add(f.rot()); frame.add(f.mirrorX() ? 1 : 0);
        j.add("frame", frame);
        JsonArray parts = new JsonArray();
        JsonObject sources = new JsonObject();
        for (String part : p.parts()) {
            parts.add(part);
            writeMap(dir.resolve("parts").resolve(part + ".bin"), p.part(part));
            Project.Source s = p.source(part);
            if (s != null) sources.add(part, source(s));
        }
        j.add("parts", parts);
        j.add("sources", sources);
        JsonArray hist = new JsonArray();
        List<Project.History> oldestFirst = new ArrayList<>(p.history());
        java.util.Collections.reverse(oldestFirst);
        for (Project.History h : oldestFirst) {
            JsonObject e = new JsonObject();
            e.addProperty("seq", h.seq());
            e.addProperty("part", h.part());
            e.addProperty("existed", h.previous() != null);
            if (h.previousSource() != null) e.add("source", source(h.previousSource()));
            hist.add(e);
            Path file = dir.resolve("history").resolve(h.seq() + ".bin");
            if (h.previous() != null && !Files.exists(file)) writeMap(file, h.previous());
        }
        j.add("history", hist);
        // Remove part files of parts that are gone and history files no longer listed (undone or dropped steps).
        try (Stream<Path> s = Files.list(dir.resolve("parts"))) {
            for (Path file : s.toList()) if (!p.parts().contains(file.getFileName().toString().replace(".bin", ""))) Files.delete(file);
        }
        java.util.Set<String> listed = new java.util.HashSet<>();
        for (Project.History h : oldestFirst) listed.add(h.seq() + ".bin");
        try (Stream<Path> s = Files.list(dir.resolve("history"))) {
            for (Path file : s.toList()) if (!listed.contains(file.getFileName().toString())) Files.delete(file);
        }
        writeMap(dir.resolve("original.bin"), p.original());
        writeAtomically(dir.resolve("project.json"), GSON.toJson(j).getBytes(StandardCharsets.UTF_8));
    }

    private static JsonObject source(Project.Source s) {
        JsonObject o = new JsonObject();
        o.addProperty("code", s.code());
        if (s.file() != null) o.addProperty("file", s.file());
        return o;
    }

    private static Project.Source source(JsonObject o) {
        return o == null ? null : new Project.Source(o.get("code").getAsString(), o.has("file") ? o.get("file").getAsString() : null);
    }

    public synchronized List<Project> loadAll() throws IOException {
        List<Project> out = new ArrayList<>();
        if (!Files.isDirectory(root)) return out;
        try (Stream<Path> dirs = Files.list(root)) {
            for (Path dir : dirs.filter(d -> Files.isRegularFile(d.resolve("project.json"))).sorted().toList()) out.add(load(dir));
        }
        return out;
    }

    private Project load(Path dir) throws IOException {
        JsonObject j = GSON.fromJson(Files.readString(dir.resolve("project.json")), JsonObject.class);
        JsonArray f = j.getAsJsonArray("frame");
        Project p = new Project(j.get("name").getAsString(), j.get("world").getAsString(),
                new Transform(f.get(0).getAsInt(), f.get(1).getAsInt(), f.get(2).getAsInt(), f.get(3).getAsInt(), f.get(4).getAsInt() == 1));
        JsonObject sources = j.getAsJsonObject("sources");
        for (var e : j.getAsJsonArray("parts")) {
            String part = e.getAsString();
            p.restorePart(part, readMap(dir.resolve("parts").resolve(part + ".bin")), source(sources.getAsJsonObject(part)));
        }
        readMap(dir.resolve("original.bin")).forEach(p::recordOriginal);
        List<Project.History> hist = new ArrayList<>();
        for (var e : j.getAsJsonArray("history")) {
            JsonObject h = e.getAsJsonObject();
            long seq = h.get("seq").getAsLong();
            LongIntMap prev = h.get("existed").getAsBoolean() ? readMap(dir.resolve("history").resolve(seq + ".bin")) : null;
            hist.add(new Project.History(seq, h.get("part").getAsString(), prev, source(h.getAsJsonObject("source"))));
        }
        p.restoreHistory(hist);
        return p;
    }

    public synchronized void delete(String name) throws IOException {
        Path dir = root.resolve(name);
        if (!Files.exists(dir)) return;
        try (Stream<Path> s = Files.walk(dir)) {
            for (Path file : s.sorted(Comparator.reverseOrder()).toList()) Files.delete(file);
        }
    }

    /** Drops the oldest undo steps, across projects, until everything fits in maxBytes. Parts and originals stay. */
    public synchronized int enforceLimit(long maxBytes, Map<String, Project> live) throws IOException {
        int dropped = 0;
        while (size() > maxBytes) {
            Project oldestOwner = null;
            Project.History oldest = null;
            for (Project p : live.values()) {
                Project.History h = p.history().peekLast();
                if (h != null && (oldest == null || h.seq() < oldest.seq())) {
                    oldest = h;
                    oldestOwner = p;
                }
            }
            if (oldest == null) break;
            oldestOwner.history().pollLast();
            Files.deleteIfExists(root.resolve(oldestOwner.name()).resolve("history").resolve(oldest.seq() + ".bin"));
            save(oldestOwner);
            dropped++;
        }
        return dropped;
    }

    private long size() throws IOException {
        if (!Files.isDirectory(root)) return 0;
        try (Stream<Path> s = Files.walk(root)) {
            long n = 0;
            for (Path p : s.filter(Files::isRegularFile).toList()) n += Files.size(p);
            return n;
        }
    }

    private void writeMap(Path file, LongIntMap map) throws IOException {
        Map<Integer, Integer> index = new HashMap<>();
        List<String> names = new ArrayList<>();
        map.forEach((pos, s) -> index.computeIfAbsent(s, k -> {
            names.add(palette.name(k));
            return names.size() - 1;
        }));
        Path tmp = file.resolveSibling(file.getFileName() + ".tmp");
        try (DataOutputStream out = new DataOutputStream(new BufferedOutputStream(new DeflaterOutputStream(Files.newOutputStream(tmp))))) {
            out.writeInt(MAGIC);
            out.writeInt(names.size());
            for (String n : names) out.writeUTF(n);
            out.writeInt(map.size());
            try {
                map.forEach((pos, s) -> {
                    try {
                        out.writeLong(pos);
                        out.writeInt(index.get(s));
                    } catch (IOException e) {
                        throw new UncheckedIOException(e);
                    }
                });
            } catch (UncheckedIOException e) {
                throw e.getCause();
            }
        }
        Files.move(tmp, file, StandardCopyOption.REPLACE_EXISTING, StandardCopyOption.ATOMIC_MOVE);
    }

    private LongIntMap readMap(Path file) throws IOException {
        try (DataInputStream in = new DataInputStream(new BufferedInputStream(new InflaterInputStream(Files.newInputStream(file))))) {
            if (in.readInt() != MAGIC) throw new IOException(file + " is not a Craftwire build file");
            int[] ids = new int[in.readInt()];
            for (int i = 0; i < ids.length; i++) {
                String name = in.readUTF();
                try {
                    ids[i] = palette.id(name);
                } catch (IllegalArgumentException e) {
                    warnings.add(file + ": " + name + " no longer exists; loaded as air");
                    ids[i] = palette.air();
                }
            }
            int n = in.readInt();
            LongIntMap m = new LongIntMap(n);
            for (int i = 0; i < n; i++) {
                long pos = in.readLong();
                m.put(pos, ids[in.readInt()]);
            }
            return m;
        }
    }

    private static void writeAtomically(Path file, byte[] data) throws IOException {
        Path tmp = file.resolveSibling(file.getFileName() + ".tmp");
        Files.write(tmp, data);
        Files.move(tmp, file, StandardCopyOption.REPLACE_EXISTING, StandardCopyOption.ATOMIC_MOVE);
    }
}

package com.uxplima.craftwire.build;

/** "oak_stairs" matches every oak_stairs state; "oak_stairs[facing=south]" matches states with those properties. */
public final class BlockMatch {
    private final String id;
    private final String[] props;

    public BlockMatch(String spec) {
        String s = spec.strip();
        if (!s.contains(":")) s = "minecraft:" + s;
        int b = s.indexOf('[');
        id = b < 0 ? s : s.substring(0, b);
        props = b < 0 ? new String[0] : s.substring(b + 1, s.length() - 1).split(",");
    }

    public boolean test(String fullState) {
        int b = fullState.indexOf('[');
        String fid = b < 0 ? fullState : fullState.substring(0, b);

package com.uxplima.craftwire.build;

import java.util.ArrayDeque;
import java.util.Deque;

/** One run of a build script: the frame stack, the current part's buffer, world reads and printed output. */
public final class BuildContext implements Placer {
    private final StatePalette palette;
    private final WorldReader reader;
    private final long limit;
    private final long seed;
    private final Deque<Transform> frames = new ArrayDeque<>();
    private final BadBlocks bad = new BadBlocks();
    private final StringBuilder out = new StringBuilder();
    private EditBuffer buffer;

    public BuildContext(StatePalette palette, WorldReader reader, Transform root, long limit, long seed) {
        this.palette = palette;
        this.reader = reader;
        this.limit = limit;
        this.seed = seed;
        frames.push(root);
        startPart();
    }

    public void startPart() {
        buffer = new EditBuffer(limit);
        while (frames.size() > 1) frames.pop();
    }

    public EditBuffer buffer() { return buffer; }
    public StatePalette palette() { return palette; }
    public long seed() { return seed; }
    public BadBlocks bad() { return bad; }
    public String output() { return out.toString(); }

    public int state(String spec) {
        try {
            return palette.id(spec);
        } catch (IllegalArgumentException e) {
            bad.add(spec, palette.suggest(spec, 3));
            return palette.air();
        }
    }

    @Override public void place(int x, int y, int z, BlockPick b) {
        int s = b.pick(x, y, z);
        if (s < 0) return;
        Transform t = frames.peek();
        buffer.put(t.worldX(x, z), t.worldY(y), t.worldZ(x, z), t.state(s, palette));
    }

    public void push(Transform child) {
        frames.push(frames.peek().then(child));
    }

    public void pop() {
        if (frames.size() == 1) throw new IllegalStateException("pop without push");
        frames.pop();
    }

    /** The state at a local position: this run's placement if any, else the world. */
    public int read(int x, int y, int z) {
        Transform t = frames.peek();
        int wx = t.worldX(x, z), wy = t.worldY(y), wz = t.worldZ(x, z);
        int s = buffer.get(wx, wy, wz);
        return s != LongIntMap.NONE ? s : reader.read(wx, wy, wz);
    }

    /** Ground height at a local column, relative to the current frame's y. */
    public int ground(int x, int z) {
        Transform t = frames.peek();
        return reader.ground(t.worldX(x, z), t.worldZ(x, z)) - t.oy();
    }

    public void print(String s) {
        if (out.length() < 20_000) out.append(s).append('\n');
    }
}

    if (typeof b === "string") return cw.block(b);

// BuildScriptRunner.java
package com.uxplima.craftwire.script;

import com.uxplima.craftwire.build.BuildApi;
import com.uxplima.craftwire.build.BuildContext;
import com.uxplima.craftwire.build.BuildError;
import com.uxplima.craftwire.build.EditBuffer;
import java.io.IOException;
import java.io.InputStream;
import java.io.UncheckedIOException;
import java.nio.charset.StandardCharsets;
import java.util.ArrayList;
import java.util.List;
import java.util.concurrent.Executors;
import java.util.concurrent.ScheduledExecutorService;
import java.util.concurrent.ScheduledFuture;
import java.util.concurrent.TimeUnit;
import java.util.concurrent.atomic.AtomicBoolean;
import java.util.regex.Pattern;
import org.graalvm.polyglot.Context;
import org.graalvm.polyglot.Engine;
import org.graalvm.polyglot.HostAccess;
import org.graalvm.polyglot.PolyglotException;
import org.graalvm.polyglot.Source;
import org.graalvm.polyglot.Value;
import org.graalvm.polyglot.io.IOAccess;

/**
 * Runs build scripts: a fresh GraalJS context per run that can reach only __cw (no Java classes, files or threads).
 * A file may declare parts with part(name, fn); without parts the whole script is one part.
 */
public final class BuildScriptRunner implements AutoCloseable {
    public record Part(String name, EditBuffer buffer) {}

    public record Result(List<Part> parts, String output) {}

    private static final Pattern NAME = Pattern.compile("[A-Za-z0-9_-]{1,64}");

    private final ClassLoader loader;
    private final String prelude;
    private final ScheduledExecutorService watchdog = Executors.newSingleThreadScheduledExecutor(r -> {
        Thread t = new Thread(r, "craftwire-build-watchdog");
        t.setDaemon(true);
        return t;
    });
    private Engine engine;

    public BuildScriptRunner(ClassLoader loader) {
        this.loader = loader;
        try (InputStream in = BuildScriptRunner.class.getResourceAsStream("/craftwire/build-api.js")) {
            this.prelude = new String(in.readAllBytes(), StandardCharsets.UTF_8);
        } catch (IOException e) {
            throw new UncheckedIOException(e);
        }
    }

    private synchronized Engine engine() {
        if (engine == null) engine = Engine.newBuilder("js").option("engine.WarnInterpreterOnly", "false").build();
        return engine;
    }

    public Result run(String code, String file, String onlyPart, String defaultPart, BuildContext ctx, long timeoutMs) {
        if (!NAME.matcher(defaultPart).matches()) throw badName(defaultPart);
        Thread thread = Thread.currentThread();
        ClassLoader previous = thread.getContextClassLoader();
        thread.setContextClassLoader(loader);
        AtomicBoolean timedOut = new AtomicBoolean();
        try (Context js = Context.newBuilder("js").engine(engine()).allowHostAccess(HostAccess.ALL)
                .allowHostClassLookup(name -> false).allowIO(IOAccess.NONE).allowCreateThread(false)
                .out(OutputStreamSink.INSTANCE).err(OutputStreamSink.INSTANCE).build()) {
            ScheduledFuture<?> kill = watchdog.schedule(() -> {
                timedOut.set(true);
                js.close(true);
            }, timeoutMs, TimeUnit.MILLISECONDS);
            try {
                js.getBindings("js").putMember("__cw", new BuildApi(ctx));
                js.eval(Source.newBuilder("js", prelude, "build-api.js").buildLiteral());
                js.eval(Source.newBuilder("js", code, file == null ? "build.js" : file).buildLiteral());
                Value declared = js.getBindings("js").getMember("__parts");
                List<Part> parts = new ArrayList<>();
                if (declared.getArraySize() == 0) {
                    parts.add(new Part(defaultPart, ctx.buffer()));
                } else {
                    if (ctx.buffer().size() > 0) {
                        throw new BuildError("SCRIPT_ERROR", "Blocks were placed outside part(...) in a file that declares parts",
                                "Move every placement into a part(name, () => { ... }) block.");
                    }
                    List<String> names = new ArrayList<>();
                    for (long i = 0; i < declared.getArraySize(); i++) names.add(declared.getArrayElement(i).getArrayElement(0).asString());
                    if (onlyPart != null && !names.contains(onlyPart)) {
                        throw new BuildError("BAD_ARGUMENT", "No part named " + onlyPart + " (parts: " + String.join(", ", names) + ")", "Pass one of those names, or leave part out to run all.");
                    }
                    for (long i = 0; i < declared.getArraySize(); i++) {
                        Value entry = declared.getArrayElement(i);
                        String name = entry.getArrayElement(0).asString();

                if (e.isHostException() && e.asHostException() instanceof IllegalArgumentException iae) {

                }
                throw new BuildError("SCRIPT_ERROR", ScriptEngine.describe(e), "Fix the script and run the build again; nothing was written.");
            } finally {
                kill.cancel(false);
            }
        } catch (IllegalStateException closed) {

                throw new BuildError("TIMEOUT", "The script ran longer than " + timeoutMs + " ms and was cancelled; nothing was written.",
                        "Look for an endless loop, or raise timeoutMs (max 300000).");

        } finally {
            thread.setContextClassLoader(previous);

                return Block.getId(BlockStateParser.parseForBlock(BuiltInRegistries.BLOCK, s, false).blockState());
            } catch (CommandSyntaxException e) {
                throw new IllegalArgumentException(e.getMessage());
            }
        });

        return BlockStateParser.serialize(Block.stateById(id));
    }

        return air;
    }

    @Override public boolean isAir(int id) {
        return Block.stateById(id).isAir();
    }

    @Override public int rotate(int id, int quarterTurns) {
        Rotation r = switch (quarterTurns & 3) {
            case 1 -> Rotation.CLOCKWISE_90;
            case 2 -> Rotation.CLOCKWISE_180;
            case 3 -> Rotation.COUNTERCLOCKWISE_90;
            default -> Rotation.NONE;
        };
        return Block.getId(Block.stateById(id).rotate(r));
    }

    @Override public int mirror(int id, Axis axis) {
        // FRONT_BACK negates x (east <-> west); LEFT_RIGHT negates z (north <-> south).
        return Block.getId(Block.stateById(id).mirror(axis == Axis.X ? Mirror.FRONT_BACK : Mirror.LEFT_RIGHT));
    }

    @Override public List<String> suggest(String spec, int max) {
        String s = spec.strip();
        int b = s.indexOf('[');
        String base = (b < 0 ? s : s.substring(0, b)).replace("minecraft:", "");
        return BuiltInRegistries.BLOCK.keySet().stream()
                .map(k -> k.getPath())
                .sorted(Comparator.comparingInt((String k) -> distance(base, k)).thenComparing(k -> k))
                .limit(max).map(k -> "minecraft:" + k).toList();
    }

    static int distance(String a, String b) {
        int[] prev = new int[b.length() + 1], cur = new int[b.length() + 1];
        for (int j = 0; j <= b.length(); j++) prev[j] = j;
        for (int i = 1; i <= a.length(); i++) {
            cur[0] = i;
            for (int j = 1; j <= b.length(); j++) {
                cur[j] = Math.min(Math.min(cur[j - 1] + 1, prev[j] + 1), prev[j - 1] + (a.charAt(i - 1) == b.charAt(j - 1) ? 0 : 1));
            }
            int[] t = prev; prev = cur; cur = t;
        }
        return prev[b.length()];
    }
}

// agent-paper/.../paper/build/TickBudget.java
package com.uxplima.craftwire.paper.build;

/** At most 8 ms of build writes per 50 ms window on each thread (Paper: the main thread; Folia: each region thread). */
final class TickBudget {
    static final long BUDGET_NANOS = 8_000_000L;
    private static final long WINDOW_NANOS = 50_000_000L;
    private static final ThreadLocal<long[]> WINDOW = ThreadLocal.withInitial(() -> new long[] {System.nanoTime(), 0});

    private TickBudget() {}

    static boolean exhausted() {
        long[] w = WINDOW.get();
        long now = System.nanoTime();
        if (now - w[0] >= WINDOW_NANOS) {
            w[0] = now;
            w[1] = 0;
        }
        return w[1] >= BUDGET_NANOS;
    }

    static void spend(long nanos) {
        WINDOW.get()[1] += nanos;
    }
}

final class PaperWorldReader implements WorldReader {
    private record Copy(PalettedContainer<BlockState>[] sections, int[] ground) {}

    private final Sync sync;
    private final World world;
    private final ServerLevel level;
    private final Map<Long, Copy> chunks = new ConcurrentHashMap<>();

    PaperWorldReader(Sync sync, World world) {
        this.sync = sync;
        this.world = world;
        this.level = ((CraftWorld) world).getHandle();
    }

    @Override public int read(int x, int y, int z) {
        if (y < level.getMinY() || y > level.getMaxY()) return BuildStates.INSTANCE.air();
        Copy c = chunk(x >> 4, z >> 4);
        return BuildStates.INSTANCE.id(c.sections()[level.getSectionIndex(y)].get(x & 15, y & 15, z & 15));
    }

    @Override public int ground(int x, int z) {
        return chunk(x >> 4, z >> 4).ground()[(z & 15) << 4 | (x & 15)];
    }

    @SuppressWarnings("unchecked")
    private Copy chunk(int cx, int cz) {
        return chunks.computeIfAbsent(Changes.chunkKey(cx, cz), k -> sync.loaded(world, cx, cz, () -> {
            LevelChunk ch = level.getChunk(cx, cz);
            LevelChunkSection[] s = ch.getSections();
            PalettedContainer<BlockState>[] copy = new PalettedContainer[s.length];
            for (int i = 0; i < s.length; i++) copy[i] = s[i].getStates().copy();
            int[] ground = new int[256];
            for (int z = 0; z < 16; z++) for (int x = 0; x < 16; x++) ground[z << 4 | x] = ch.getHeight(Heightmap.Types.MOTION_BLOCKING_NO_LEAVES, x, z);
            return new Copy(copy, ground);
        }).join());
    }

    static CompletableFuture<Outcome> apply(Sync sync, World world, Project project, Changes changes) {
        ServerLevel level = ((CraftWorld) world).getHandle();
        Map<Long, long[]> byChunk = changes.byChunk();
        List<Long> keys = new ArrayList<>(byChunk.keySet());
        Map<Long, List<Long>> written = new ConcurrentHashMap<>();
        AtomicInteger changed = new AtomicInteger(), outside = new AtomicInteger(), unsupported = new AtomicInteger();
        List<String> unsupportedAt = Collections.synchronizedList(new ArrayList<>());
        CompletableFuture<Void> chain = CompletableFuture.completedFuture(null);
        for (int from = 0; from < keys.size(); from += BATCH) {
            List<Long> batch = keys.subList(from, Math.min(keys.size(), from + BATCH));
            chain = chain.thenCompose(v -> CompletableFuture.allOf(batch.stream().map(k -> {
                int cx = (int) (k >> 32), cz = (int) (long) k;
                return world.getChunkAtAsync(cx, cz).thenCompose(ch -> slice(sync, world, cx, cz,
                        new Job(level, project, changes, byChunk.get(k), written.computeIfAbsent(k, x -> Collections.synchronizedList(new ArrayList<>())), changed, outside)));
            }).toArray(CompletableFuture[]::new)));
        }
        CompletableFuture<Outcome> done = chain.thenCompose(v -> CompletableFuture.allOf(written.entrySet().stream().map(e -> {
            int cx = (int) (e.getKey() >> 32), cz = (int) (long) e.getKey();
            return sync.region(world, cx, cz, () -> {
                connectAndCheck(level, e.getValue(), unsupported, unsupportedAt);
                return null;
            });
        }).toArray(CompletableFuture[]::new))).thenApply(v -> new Outcome(changed.get(), outside.get(), unsupported.get(), List.copyOf(unsupportedAt)));
        return done.exceptionallyCompose(t -> rollback(sync, world, level, project, written).thenCompose(v ->
                CompletableFuture.failedFuture(new AgentError("APPLY_FAILED", "Writing the build failed: " + Sync.explainThread(t).getMessage()
                        + "; the chunks already written were put back", "Check the server log, then run the build again."))));
    }

    private static final class Job {
        final ServerLevel level;
        final Project project;
        final Changes changes;
        final long[] positions;
        final List<Long> written;
        final AtomicInteger changed, outside;
        int next;

        Job(ServerLevel level, Project project, Changes changes, long[] positions, List<Long> written, AtomicInteger changed, AtomicInteger outside) {
            this.level = level; this.project = project; this.changes = changes; this.positions = positions; this.written = written;
            this.changed = changed; this.outside = outside;
        }
    }

    private static CompletableFuture<Void> slice(Sync sync, World world, int cx, int cz, Job j) {
        return sync.region(world, cx, cz, () -> {
            BlockPos.MutableBlockPos m = new BlockPos.MutableBlockPos();
            while (j.next < j.positions.length && !TickBudget.exhausted()) {
                long start = System.nanoTime();
                int end = Math.min(j.positions.length, j.next + 256);
                for (; j.next < end; j.next++) {
                    long p = j.positions[j.next];
                    int y = Pos.y(p);
                    if (y < j.level.getMinY() || y > j.level.getMaxY()) {
                        j.outside.incrementAndGet();
                        continue;
                    }
                    m.set(Pos.x(p), y, Pos.z(p));
                    BlockState current = j.level.getBlockState(m);
                    j.project.recordOriginal(p, Block.getId(current));
                    BlockState target = Block.stateById(j.changes.targets().get(p));
                    if (current == target) continue;
                    j.level.setBlock(m, target, FLAGS);
                    j.written.add(p);
                    j.changed.incrementAndGet();
                }
                TickBudget.spend(System.nanoTime() - start);
            }
            return j.next < j.positions.length;
        }).thenCompose(more -> more ? slice(sync, world, cx, cz, j) : CompletableFuture.completedFuture(null));
    }

    private static boolean connects(BlockState s) {
        Block b = s.getBlock();
        return b instanceof StairBlock || b instanceof CrossCollisionBlock || b instanceof WallBlock;
    }

    private static void connectAndCheck(ServerLevel level, List<Long> written, AtomicInteger unsupported, List<String> at) {
        BlockPos.MutableBlockPos m = new BlockPos.MutableBlockPos();
        synchronized (written) {
            for (long p : written) {
                m.set(Pos.x(p), Pos.y(p), Pos.z(p));
                BlockState s = level.getBlockState(m);
                if (connects(s)) {
                    BlockState shaped = Block.updateFromNeighbourShapes(s, level, m);
                    if (shaped != s) level.setBlock(m, shaped, FLAGS);
                }
                if (!s.isAir() && !s.canSurvive(level, m)) {
                    unsupported.incrementAndGet();
                    if (at.size() < 5) at.add(m.getX() + "," + m.getY() + "," + m.getZ() + " " + BuildStates.INSTANCE.name(Block.getId(s)));
                }
            }
        }
    }

    private static CompletableFuture<Void> rollback(Sync sync, World world, ServerLevel level, Project project, Map<Long, List<Long>> written) {
        return CompletableFuture.allOf(written.entrySet().stream().map(e -> sync.region(world, (int) (e.getKey() >> 32), (int) (long) e.getKey(), () -> {
            BlockPos.MutableBlockPos m = new BlockPos.MutableBlockPos();
            synchronized (e.getValue()) {
                for (long p : e.getValue()) {
                    int o = project.originalOf(p);
                    if (o >= 0) level.setBlock(m.set(Pos.x(p), Pos.y(p), Pos.z(p)), Block.stateById(o), FLAGS);
                }
            }
            return null;
        }).exceptionally(t -> null)).toArray(CompletableFuture[]::new));
    }
}

/** Build projects: scripts run on two worker threads, one request at a time per project, stored under plugins/Craftwire/builds. */
public final class BuildService {
    private static final Pattern NAME = Pattern.compile("[A-Za-z0-9_-]{1,64}");
    private final CraftwirePlugin plugin;
    private final ProjectStore store;
    private final BuildScriptRunner runner;
    private final Map<String, Project> projects = new ConcurrentHashMap<>();
    private final Map<String, CompletableFuture<?>> tails = new ConcurrentHashMap<>();
    private final ExecutorService workers;

    public BuildService(CraftwirePlugin plugin) {
        this.plugin = plugin;
        this.store = new ProjectStore(plugin.getDataFolder().toPath().resolve("builds"), BuildStates.INSTANCE);
        this.runner = new BuildScriptRunner(plugin.getClass().getClassLoader());
        AtomicInteger n = new AtomicInteger();
        this.workers = Executors.newFixedThreadPool(2, r -> {
            Thread t = new Thread(r, "craftwire-build-" + n.incrementAndGet());
            t.setDaemon(true);
            return t;
        });
        reload();
    }

    /** Drops projects in memory and loads them from disk again (startup, and the restart IT). */
    public synchronized void reload() {
        projects.clear();
        try {
            for (Project p : store.loadAll()) projects.put(p.name(), p);
        } catch (IOException e) {
            plugin.getLogger().warning("Could not load build projects: " + e);
        }
        store.warnings().forEach(w -> plugin.getLogger().warning(w));
    }

    public void close() {
        workers.shutdownNow();
        runner.close();
    }

    /** Runs work after the previous request on the same project, on a worker thread. */
    private CompletableFuture<JsonElement> queued(String project, java.util.function.Supplier<CompletableFuture<JsonElement>> work) {
        CompletableFuture<JsonElement> mine = new CompletableFuture<>();
        tails.compute(project, (k, prev) -> {
            CompletableFuture<?> before = prev == null ? CompletableFuture.completedFuture(null) : prev.handle((v, t) -> null);
            before.thenComposeAsync(v -> work.get(), workers).whenComplete((v, t) -> {
                if (t != null) mine.completeExceptionally(unwrap(t));
                else mine.complete(v);
            });
            return mine;
        });
        return mine;
    }

    static Throwable unwrap(Throwable t) {
        Throwable c = t instanceof CompletionException && t.getCause() != null ? t.getCause() : t;
        return c instanceof BuildError b ? new AgentError(b.code(), b.getMessage(), b.hint()) : c;
    }

    private static String checkName(String name, String what) {
        if (!NAME.matcher(name).matches()) throw Args.invalid(what + " names use letters, digits, _ and - (at most 64): " + name);
        return name;
    }

    private static int quarterTurns(JsonObject p) {
        int deg = Args.optInt(p, "rotation").orElse(0);
        if (deg % 90 != 0) throw Args.invalid("rotation must be 0, 90, 180 or 270");
        return Math.floorMod(deg / 90, 4);
    }

    private static String mirror(JsonObject p) {
        String m = Args.optString(p, "mirror").orElse("none");
        return switch (m) {
            case "none" -> "";
            case "x", "z" -> m;
            default -> throw Args.invalid("mirror must be none, x or z");
        };
    }

    private static Transform frame(JsonObject origin, JsonObject p) {
        return Transform.of(Args.integer(origin, "x"), Args.integer(origin, "y"), Args.integer(origin, "z"), quarterTurns(p), mirror(p));
    }

    public CompletableFuture<JsonElement> run(JsonObject p) {
        AgentConfig config = plugin.agentConfig();
        config.require(config.allowBuild(), "allow-build");
        String name = checkName(Args.string(p, "project"), "Project");
        return queued(name, () -> {
            long started = System.currentTimeMillis();
            Project project = projects.get(name);
            if (project == null) {
                if (!p.has("origin")) {
                    throw new AgentError("BAD_ARGUMENT", "Project " + name + " is new, so it needs an origin {x,y,z}", "Pass origin on the first build of a project.");
                }
                project = new Project(name, Args.world(p).getName(), frame(Args.object(p, "origin"), p));
            } else if (p.has("origin") && !frame(Args.object(p, "origin"), p).equals(project.frame())) {
                throw new AgentError("BAD_ARGUMENT", "Project " + name + " already sits at another origin/rotation",
                        "Use build_manage {action:'move'} to move or turn it, or leave origin out.");
            }
            Project pr = project;
            World world = world(pr);
            String code = Args.string(p, "code");
            String file = Args.optString(p, "file").orElse(null);
            long seed = Args.optLong(p, "seed").orElse(0L);
            long timeout = Math.min(300_000, Args.optLong(p, "timeoutMs").orElse(60_000L));
            BuildContext ctx = new BuildContext(BuildStates.INSTANCE, new PaperWorldReader(plugin.sync(), world), pr.frame(), config.maxBuildVolume(), seed);
            BuildScriptRunner.Result result = runner.run(code, file, Args.optString(p, "part").orElse(null), "main", ctx, timeout);
            boolean dry = Args.bool(p, "dryRun", false);
            JsonObject out = new JsonObject();
            out.addProperty("project", name);
            JsonArray parts = new JsonArray();
            List<String> warnings = new ArrayList<>();
            int[] totals = new int[3];   // changed, removed, blocks
            CompletableFuture<Void> chain = CompletableFuture.completedFuture(null);
            for (BuildScriptRunner.Part part : result.parts()) {
                chain = chain.thenCompose(v -> {
                    Changes changes = pr.stage(part.name(), part.buffer().blocks());
                    JsonObject pj = new JsonObject();
                    pj.addProperty("part", part.name());
                    pj.addProperty("blocks", part.buffer().size());
                    totals[2] += part.buffer().size();
                    if (part.buffer().outOfRange() > 0) warnings.add(part.buffer().outOfRange() + " blocks of " + part.name() + " were outside the world and dropped");
                    if (dry) {
                        pj.addProperty("wouldChange", changes.size());
                        parts.add(pj);
                        return CompletableFuture.completedFuture(null);
                    }
                    return apply(world, pr, changes).thenAccept(o -> {
                        pr.commit(part.name(), part.buffer().blocks(), new com.uxplima.craftwire.build.Project.Source(code, file), true);
                        projects.put(name, pr);
                        pj.addProperty("changed", o.changed());
                        pj.addProperty("removed", changes.removed());
                        totals[0] += o.changed();
                        totals[1] += changes.removed();
                        if (o.outsideHeight() > 0) warnings.add(o.outsideHeight() + " blocks of " + part.name() + " were outside the build height and skipped");
                        if (o.unsupported() > 0) warnings.add(o.unsupported() + " blocks need support they do not have (e.g. " + String.join("; ", o.unsupportedAt()) + ")");
                        parts.add(pj);
                    });
                });
            }
            return chain.thenApply(v -> {
                if (!dry) save(pr);
                out.add("parts", parts);
                out.addProperty("changed", totals[0]);
                out.addProperty("removed", totals[1]);
                out.addProperty("blocks", totals[2]);
                out.add("bbox", bbox(result));
                out.add("palette", palette(result));
                JsonArray w = new JsonArray();
                warnings.forEach(w::add);
                if (overlaps(pr, result)) w.add("parts overlap; the part run last covers the others");
                out.add("warnings", w);
                if (!result.output().isEmpty()) out.addProperty("output", result.output());
                out.addProperty("ms", System.currentTimeMillis() - started);
                return (JsonElement) out;
            });
        });
    }

            store.save(p);

    /**
     * Applies on the owning threads, then continues on a build worker: scripts, diffs and disk writes never run on a
     * server thread (a script read would wait for that very thread).
     */
    private CompletableFuture<Applier.Outcome> apply(World world, Project pr, Changes changes) {
        return Applier.apply(plugin.sync(), world, pr, changes).thenApplyAsync(o -> o, workers);
    }

    private static World world(Project p) {
        World w = Bukkit.getWorld(p.world());
        if (w == null) throw new AgentError("WORLD_NOT_FOUND", "World " + p.world() + " is not loaded", "Load that world, then retry.");
        return w;
    }

    private static JsonElement bbox(BuildScriptRunner.Result r) {
        int[] b = null;
        for (BuildScriptRunner.Part part : r.parts()) {
            int[] pb = part.buffer().bbox();
            if (pb == null) continue;
            if (b == null) b = pb.clone();
            else for (int i = 0; i < 3; i++) {
                b[i] = Math.min(b[i], pb[i]);
                b[i + 3] = Math.max(b[i + 3], pb[i + 3]);
            }
        }
        if (b == null) return com.google.gson.JsonNull.INSTANCE;
        JsonObject o = new JsonObject();
        o.add("min", xyz(b[0], b[1], b[2]));
        o.add("max", xyz(b[3], b[4], b[5]));
        return o;
    }

    static JsonObject xyz(int x, int y, int z) {
        JsonObject o = new JsonObject();
        o.addProperty("x", x);
        o.addProperty("y", y);
        o.addProperty("z", z);
        return o;
    }

    private static JsonArray palette(BuildScriptRunner.Result r) {
        Map<Integer, Integer> counts = new HashMap<>();
        for (BuildScriptRunner.Part part : r.parts()) part.buffer().blocks().forEach((pos, s) -> counts.merge(s, 1, Integer::sum));
        JsonArray a = new JsonArray();
        counts.entrySet().stream().sorted((x, y) -> y.getValue() - x.getValue()).limit(10).forEach(e -> {
            JsonArray row = new JsonArray();
            row.add(BuildStates.INSTANCE.name(e.getKey()));
            row.add(e.getValue());
            a.add(row);
        });
        return a;
    }

    private static boolean overlaps(Project p, BuildScriptRunner.Result r) {
        List<String> names = p.parts();
        if (names.size() < 2) return false;
        for (BuildScriptRunner.Part part : r.parts()) {
            boolean[] hit = {false};
            for (String other : names) {
                if (other.equals(part.name())) continue;
                LongIntMap o = p.part(other);
                if (o == null) continue;
                part.buffer().blocks().forEach((pos, s) -> { if (!hit[0] && o.containsKey(pos)) hit[0] = true; });
                if (hit[0]) return true;
            }
        }
        return false;
    }

    public CompletableFuture<JsonElement> manage(JsonObject p) {
        AgentConfig config = plugin.agentConfig();
        config.require(config.allowBuild(), "allow-build");
        String action = Args.string(p, "action");
        if (action.equals("list")) return CompletableFuture.completedFuture(list());
        String name = checkName(Args.string(p, "project"), "Project");
        return queued(name, () -> {
            Project pr = projects.get(name);
            if (pr == null) throw new AgentError("PROJECT_NOT_FOUND", "No build project named " + name, "build_manage {action:'list'} shows the projects.");
            World world = world(pr);
            return switch (action) {
                case "undo" -> undo(pr, world, Math.max(1, Args.optInt(p, "steps").orElse(1)));
                case "remove" -> {
                    String part = Args.string(p, "part");
                    if (pr.part(part) == null) throw new AgentError("BAD_ARGUMENT", "Project " + name + " has no part " + part, "Parts: " + pr.parts());
                    yield apply(world, pr, pr.stage(part, null)).thenApply(o -> {
                        pr.commit(part, null, null, true);
                        save(pr);
                        return summary(pr, o.changed());
                    });
                }
                case "clear" -> apply(world, pr, pr.clearAll()).thenApply(o -> {
                    forget(pr);
                    JsonObject r = new JsonObject();
                    r.addProperty("project", name);
                    r.addProperty("restored", o.changed());
                    return (JsonElement) r;
                });
                case "move" -> move(pr, world, p);
                case "commit" -> {
                    forget(pr);
                    JsonObject r = new JsonObject();
                    r.addProperty("project", name);
                    r.addProperty("committed", true);
                    yield CompletableFuture.completedFuture((JsonElement) r);
                }
                default -> throw Args.invalid("action must be list, undo, remove, clear, move or commit");
            };
        });
    }

    private void forget(Project pr) {
        projects.remove(pr.name());
        pr.reset();
        try {
            store.delete(pr.name());
        } catch (IOException e) {
            plugin.getLogger().warning("Could not delete build project " + pr.name() + ": " + e);
        }
    }

    private CompletableFuture<JsonElement> undo(Project pr, World world, int steps) {
        CompletableFuture<Integer> chain = CompletableFuture.completedFuture(0);
        for (int i = 0; i < steps; i++) {
            chain = chain.thenCompose(n -> {
                Project.History h = pr.popHistory();
                if (h == null) return CompletableFuture.completedFuture(n);
                return apply(world, pr, pr.stage(h.part(), h.previous())).thenApply(o -> {
                    pr.commit(h.part(), h.previous(), h.previousSource(), false);
                    return n + o.changed();
                });
            });
        }
        return chain.thenApply(changed -> {
            save(pr);
            return summary(pr, changed);
        });
    }

    private CompletableFuture<JsonElement> move(Project pr, World world, JsonObject p) {
        Transform old = pr.frame();
        JsonObject origin = p.has("origin") ? Args.object(p, "origin") : BuildService.xyz(old.ox(), old.oy(), old.oz());
        Transform next = frame(origin, p);
        Map<String, Project.Source> sources = new LinkedHashMap<>();
        for (String part : pr.parts()) sources.put(part, pr.source(part));
        return apply(world, pr, pr.clearAll()).thenCompose(o -> {
            pr.reset();
            pr.setFrame(next);
            CompletableFuture<Integer> chain = CompletableFuture.completedFuture(0);
            for (Map.Entry<String, Project.Source> e : sources.entrySet()) {
                chain = chain.thenCompose(n -> {
                    Project.Source s = e.getValue();
                    BuildContext ctx = new BuildContext(BuildStates.INSTANCE, new PaperWorldReader(plugin.sync(), world), next, plugin.agentConfig().maxBuildVolume(), 0);
                    BuildScriptRunner.Result r = runner.run(s.code(), s.file(), e.getKey().equals("main") && !s.code().contains("part(") ? null : e.getKey(), e.getKey(), ctx, 300_000);
                    EditBuffer buf = r.parts().get(0).buffer();
                    return apply(world, pr, pr.stage(e.getKey(), buf.blocks())).thenApply(o2 -> {
                        pr.commit(e.getKey(), buf.blocks(), s, false);
                        return n + o2.changed();
                    });
                });
            }
            return chain;
        }).thenApply(changed -> {
            save(pr);
            return summary(pr, changed);
        });
    }

    private JsonElement summary(Project pr, int changed) {
        JsonObject r = new JsonObject();
        r.addProperty("project", pr.name());
        r.addProperty("changed", changed);
        JsonArray parts = new JsonArray();
        pr.parts().forEach(parts::add);
        r.add("parts", parts);
        r.addProperty("undoSteps", pr.history().size());
        return r;
    }

    private JsonElement list() {
        JsonArray a = new JsonArray();
        for (Project p : projects.values()) {
            JsonObject o = new JsonObject();
            o.addProperty("project", p.name());
            o.addProperty("world", p.world());
            Transform f = p.frame();
            o.add("origin", xyz(f.ox(), f.oy(), f.oz()));
            o.addProperty("rotation", f.rot() * 90);
            JsonArray parts = new JsonArray();
            for (String part : p.parts()) {
                JsonObject pj = new JsonObject();
                pj.addProperty("part", part);
                pj.addProperty("blocks", p.part(part).size());
                parts.add(pj);
            }
            o.add("parts", parts);
            o.addProperty("undoSteps", p.history().size());
            a.add(o);
        }
        JsonObject r = new JsonObject();
        r.add("projects", a);
        return r;
    }

// hub/src/build-files.ts
import { existsSync, readFileSync, realpathSync } from "node:fs";
import { isAbsolute, relative, resolve } from "node:path";
import { CraftwireError } from "./errors.js";

/**
 * A build script on the hub's machine. Over HTTP the caller is remote, so files are read only from --build-dir.
 */
export function readBuildFile(path: string, o: { dir?: string; http: boolean }, cwd: string = process.cwd()): { code: string; file: string } {
  if (o.http && o.dir === undefined) {
    throw new CraftwireError("BAD_ARGUMENT", "file is not available on this HTTP hub", "Start craftwire serve with --build-dir <dir>, or pass code instead.");
  }
  const base = o.dir !== undefined ? resolve(cwd, o.dir) : cwd;
  const full = resolve(base, path);
  if (!existsSync(full)) throw new CraftwireError("BAD_ARGUMENT", `No build file at ${full}`, "Write the script first, or check the path (relative paths start at the hub's working directory).");
  if (o.dir !== undefined) {
    const rel = relative(realpathSync(base), realpathSync(full));
    if (rel.startsWith("..") || isAbsolute(rel)) throw new CraftwireError("BAD_ARGUMENT", `${full} is outside --build-dir ${base}`, "Put build scripts inside the --build-dir folder.");
  }
  return { code: readFileSync(full, "utf8"), file: full };
}

import com.google.gson.JsonElement;
import com.google.gson.JsonObject;
import java.util.Map;
import java.util.concurrent.ConcurrentHashMap;

/** Average top and side colours per block id from the game's textures; the hub sends them with iso renders. */
public final class BlockColors {
    private static final Map<String, int[]> TABLE = new ConcurrentHashMap<>();

    private BlockColors() {}

    public static void set(JsonObject table) {
        for (Map.Entry<String, JsonElement> e : table.entrySet()) {
            var a = e.getValue().getAsJsonArray();
            TABLE.put(e.getKey(), new int[] {a.get(0).getAsInt(), a.get(1).getAsInt()});
        }
    }

    public static boolean loaded() {
        return !TABLE.isEmpty();
    }

    public static int top(String id) {
        int[] c = TABLE.get(id);
        return c == null ? -1 : c[0];
    }

    public static int side(String id) {
        int[] c = TABLE.get(id);
        return c == null ? -1 : c[1];
    }
}

import java.awt.image.BufferedImage;

/**
 * Isometric views without a client: each visible block is three shaded faces, drawn back to front. The viewer
 * stands at `corner`; `a` grows toward the viewer on the right, `b` toward the viewer on the left.
 */
public final class IsoRenderer {
    static final int MAX_FOOTPRINT = 256;
    static final long MAX_VOLUME = 8_000_000L;

    private IsoRenderer() {}

    private record Axes(boolean aIsX, boolean aFlip, boolean bFlip) {}

    private static Axes axes(String corner) {
        return switch (corner) {
            case "se" -> new Axes(true, false, false);   // a = x, b = z
            case "sw" -> new Axes(false, false, true);   // a = z, b = -x
            case "nw" -> new Axes(true, true, true);     // a = -x, b = -z
            case "ne" -> new Axes(false, true, false);   // a = -z, b = x
            default -> throw Args.invalid("corner must be ne, nw, se or sw");
        };
    }

    public static BufferedImage sheet(BlockSource src, Box box, int size) {
        int half = size / 2;
        BufferedImage out = new BufferedImage(half * 2, half * 2, BufferedImage.TYPE_INT_RGB);
        Graphics2D g = out.createGraphics();
        String[] corners = {"nw", "ne", "sw", "se"};
        for (int i = 0; i < 4; i++) g.drawImage(render(src, box, corners[i], half), (i % 2) * half, (i / 2) * half, null);
        g.dispose();
        return out;
    }

    public static BufferedImage render(BlockSource src, Box box, String corner, int size) {
        if (box.sizeX() > MAX_FOOTPRINT || box.sizeZ() > MAX_FOOTPRINT) throw Args.invalid("iso views draw at most " + MAX_FOOTPRINT + "x" + MAX_FOOTPRINT + " blocks");
        if (box.volume() > MAX_VOLUME) throw Args.invalid("iso views draw at most " + MAX_VOLUME + " blocks");
        Axes ax = axes(corner);
        int na = ax.aIsX() ? box.sizeX() : box.sizeZ(), nb = ax.aIsX() ? box.sizeZ() : box.sizeX(), ny = box.sizeY();
        double s = Math.max(1.0, Math.min((size * 0.92) / (na + nb), (size * 0.92) / ((na + nb) / 2.0 + ny + 1)));
        double offX = size / 2.0 - (na - nb) * s / 2.0;
        double offY = (size - ((na + nb) / 2.0 + ny + 1) * s) / 2.0 + ny * s;
        BufferedImage img = new BufferedImage(size, size, BufferedImage.TYPE_INT_RGB);
        Graphics2D g = img.createGraphics();
        g.setRenderingHint(RenderingHints.KEY_ANTIALIASING, RenderingHints.VALUE_ANTIALIAS_OFF);
        g.setColor(new java.awt.Color(Shading.SKY));
        g.fillRect(0, 0, size, size);
        for (int sum = 0; sum <= na + nb - 2; sum++) {
            for (int a = Math.max(0, sum - nb + 1); a <= Math.min(na - 1, sum); a++) {
                int b = sum - a;
                int x = worldX(box, ax, a, b), z = worldZ(box, ax, a, b);
                if (!src.loaded(x, z)) continue;
                for (int dy = 0; dy < ny; dy++) {
                    int y = box.minY() + dy;
                    if (src.color(x, y, z) == 0 && src.topColor(x, y, z) == 0) continue;
                    double sx = offX + (a - b) * s, sy = offY + (a + b) * s / 2.0 - dy * s;
                    if (empty(src, box, ax, a, b, dy + 1)) face(g, shade(src.topColor(x, y, z), occlusion(src, box, ax, a, b, dy + 1)), sx, sy, s, 0);
                    if (empty(src, box, ax, a, b + 1, dy)) face(g, Shading.shade(src.sideColor(x, y, z), 204), sx, sy, s, 1);
                    if (empty(src, box, ax, a + 1, b, dy)) face(g, Shading.shade(src.sideColor(x, y, z), 166), sx, sy, s, 2);
                }
            }
        }
        g.dispose();
        PixelFont.draw(img, corner.toUpperCase(), 4, 4, Math.max(1, size / 256), Shading.LABEL);
        return img;
    }

    private static int worldX(Box box, Axes ax, int a, int b) {
        return ax.aIsX() ? (ax.aFlip() ? box.maxX() - a : box.minX() + a) : (ax.bFlip() ? box.maxX() - b : box.minX() + b);
    }

    private static int worldZ(Box box, Axes ax, int a, int b) {
        return ax.aIsX() ? (ax.bFlip() ? box.maxZ() - b : box.minZ() + b) : (ax.aFlip() ? box.maxZ() - a : box.minZ() + a);
    }

    private static boolean empty(BlockSource src, Box box, Axes ax, int a, int b, int dy) {
        int na = ax.aIsX() ? box.sizeX() : box.sizeZ(), nb = ax.aIsX() ? box.sizeZ() : box.sizeX();
        if (a < 0 || b < 0 || a >= na || b >= nb || dy >= box.sizeY()) return true;
        int x = worldX(box, ax, a, b), z = worldZ(box, ax, a, b);
        return !src.loaded(x, z) || src.color(x, box.minY() + dy, z) == 0 && src.topColor(x, box.minY() + dy, z) == 0;
    }

    /** How many of the four blocks around the one above are filled: darkens the top face a little each. */
    private static int occlusion(BlockSource src, Box box, Axes ax, int a, int b, int dy) {
        int n = 0;
        if (!empty(src, box, ax, a + 1, b, dy)) n++;
        if (!empty(src, box, ax, a - 1, b, dy)) n++;
        if (!empty(src, box, ax, a, b + 1, dy)) n++;
        if (!empty(src, box, ax, a, b - 1, dy)) n++;
        return n;
    }

    private static int shade(int rgb, int occluders) {
        return Shading.shade(rgb, 255 - 18 * occluders);
    }

    /** kind 0 = top rhombus, 1 = left side, 2 = right side; (sx, sy) is the top vertex of the top face. */
    private static void face(Graphics2D g, int rgb, double sx, double sy, double s, int kind) {
        double[][] p = switch (kind) {
            case 0 -> new double[][] {{sx, sy}, {sx + s, sy + s / 2}, {sx, sy + s}, {sx - s, sy + s / 2}};
            case 1 -> new double[][] {{sx - s, sy + s / 2}, {sx, sy + s}, {sx, sy + 2 * s}, {sx - s, sy + 1.5 * s}};
            default -> new double[][] {{sx, sy + s}, {sx + s, sy + s / 2}, {sx + s, sy + 1.5 * s}, {sx, sy + 2 * s}};
        };
        Polygon poly = new Polygon();
        for (double[] v : p) poly.addPoint((int) Math.round(v[0]), (int) Math.round(v[1]));
        g.setColor(new java.awt.Color(rgb));
        g.fillPolygon(poly);
        g.drawPolygon(poly);   // closes hairline gaps between neighbours
    }
}

    const crc = Buffer.alloc(4); crc.writeUInt32BE(crc32(td) >>> 0);

  const raw = Buffer.alloc(height * (1 + width * bpp));

// hub/src/blocks/png.ts
import { inflateSync } from "node:zlib";

/** PNG to RGBA for block textures: bit depth 8, colour types 0, 2, 3, 4, 6, not interlaced. */
export function decodePng(buf: Buffer): { width: number; height: number; rgba: Uint8Array } {
  if (buf.length < 8 || buf.readUInt32BE(0) !== 0x89504e47) throw new Error("not a PNG file");
  let p = 8, width = 0, height = 0, type = 0, depth = 0, interlace = 0;
  let palette: Buffer | undefined, trns: Buffer | undefined;
  const idat: Buffer[] = [];
  while (p < buf.length) {
    const len = buf.readUInt32BE(p), kind = buf.toString("ascii", p + 4, p + 8), data = buf.subarray(p + 8, p + 8 + len);
    if (kind === "IHDR") { width = data.readUInt32BE(0); height = data.readUInt32BE(4); depth = data[8]!; type = data[9]!; interlace = data[12]!; }
    else if (kind === "PLTE") palette = data;
    else if (kind === "tRNS") trns = data;
    else if (kind === "IDAT") idat.push(data);
    else if (kind === "IEND") break;
    p += 12 + len;
  }
  if (depth !== 8 || interlace !== 0) throw new Error(`unsupported PNG (bit depth ${depth}, interlace ${interlace})`);
  const channels = ({ 0: 1, 2: 3, 3: 1, 4: 2, 6: 4 } as Record<number, number>)[type];
  if (channels === undefined) throw new Error(`unsupported PNG colour type ${type}`);
  const raw = inflateSync(Buffer.concat(idat));
  const stride = width * channels;
  const px = new Uint8Array(height * stride);
  for (let y = 0; y < height; y++) {
    const filter = raw[y * (stride + 1)]!;
    for (let i = 0; i < stride; i++) {
      const x = raw[y * (stride + 1) + 1 + i]!;
      const a = i >= channels ? px[y * stride + i - channels]! : 0;
      const b = y > 0 ? px[(y - 1) * stride + i]! : 0;
      const c = y > 0 && i >= channels ? px[(y - 1) * stride + i - channels]! : 0;
      let v = x;
      if (filter === 1) v = x + a;
      else if (filter === 2) v = x + b;
      else if (filter === 3) v = x + ((a + b) >> 1);
      else if (filter === 4) {
        const pa = Math.abs(b - c), pb = Math.abs(a - c), pc = Math.abs(a + b - 2 * c);
        v = x + (pa <= pb && pa <= pc ? a : pb <= pc ? b : c);
      }
      px[y * stride + i] = v & 0xff;
    }
  }
  const rgba = new Uint8Array(width * height * 4);
  for (let i = 0; i < width * height; i++) {
    const o = i * 4, s = i * channels;
    if (type === 6) { rgba.set(px.subarray(s, s + 4), o); }
    else if (type === 2) { rgba.set(px.subarray(s, s + 3), o); rgba[o + 3] = 255; }
    else if (type === 0) { rgba.fill(px[s]!, o, o + 3); rgba[o + 3] = 255; }
    else if (type === 4) { rgba.fill(px[s]!, o, o + 3); rgba[o + 3] = px[s + 1]!; }
    else {
      const k = px[s]!;
      rgba[o] = palette![k * 3]!; rgba[o + 1] = palette![k * 3 + 1]!; rgba[o + 2] = palette![k * 3 + 2]!;
      rgba[o + 3] = trns && k < trns.length ? trns[k]! : 255;
    }
  }
  return { width, height, rgba };
}

const BIOME_TINT: Record<string, number> = {
  grass_block: 0x91bd59, short_grass: 0x91bd59, tall_grass: 0x91bd59, fern: 0x91bd59, large_fern: 0x91bd59, sugar_cane: 0x91bd59,

};

const tex = (ref: string) => `assets/minecraft/textures/${ref.replace("minecraft:", "")}.png`;
const model = (ref: string) => `assets/minecraft/models/${ref.replace("minecraft:", "")}.json`;

/** Average top and side colour of every block, from its blockstate's first model. Transparent textures give 0. */
export function extractBlockColors(jar: string): Record<string, [number, number]> {
  const files = readZipEntries(jar, (n) => n.startsWith("assets/minecraft/blockstates/") || n.startsWith("assets/minecraft/models/block/") || n.startsWith("assets/minecraft/textures/block/"));
  const json = (name: string): Json | undefined => { const b = files.get(name); return b ? JSON.parse(b.toString("utf8")) as Json : undefined; };
  const averages = new Map<string, number>();
  const average = (ref: string, tint?: number): number => {
    const key = `${ref}|${tint ?? ""}`;
    const cached = averages.get(key);
    if (cached !== undefined) return cached;
    const png = files.get(tex(ref));
    let out = 0;
    if (png) {
      const img = decodePng(png);
      const h = Math.min(img.height, img.width);   // animated textures: first frame
      let r = 0, g = 0, b = 0, a = 0;
      for (let i = 0; i < img.width * h; i++) {
        const w = img.rgba[i * 4 + 3]!;
        if (w < 16) continue;
        r += img.rgba[i * 4]! * w; g += img.rgba[i * 4 + 1]! * w; b += img.rgba[i * 4 + 2]! * w; a += w;
      }
      if (a > img.width * h * 255 * 0.4) {
        r /= a; g /= a; b /= a;
        if (tint !== undefined) { r = r * (tint >> 16 & 255) / 255; g = g * (tint >> 8 & 255) / 255; b = b * (tint & 255) / 255; }
        out = (Math.round(r) << 16) | (Math.round(g) << 8) | Math.round(b);
      }
    }
    averages.set(key, out);
    return out;
  };
  const textures = (ref: string, seen = 0): Record<string, string> => {
    const m = json(model(ref.includes("/") ? ref : `block/${ref}`));
    if (!m || seen > 20) return {};
    const own = (m.textures ?? {}) as Record<string, string>;
    return { ...(typeof m.parent === "string" ? textures(m.parent, seen + 1) : {}), ...own };
  };
  const resolve = (t: Record<string, string>, k: string | undefined): string | undefined => {
    let v = k === undefined ? undefined : t[k];
    for (let i = 0; v?.startsWith("#") && i < 10; i++) v = t[v.slice(1)];
    return v?.startsWith("#") ? undefined : v;
  };
  const out: Record<string, [number, number]> = {};
  for (const [name, buf] of files) {
    if (!name.startsWith("assets/minecraft/blockstates/")) continue;
    const id = name.slice("assets/minecraft/blockstates/".length, -".json".length);
    const bs = JSON.parse(buf.toString("utf8")) as Json;
    let first: unknown;
    if (bs.variants) first = Object.values(bs.variants as Json)[0];
    else if (Array.isArray(bs.multipart)) first = (bs.multipart[0] as Json).apply;
    if (Array.isArray(first)) first = first[0];
    const ref = (first as Json | undefined)?.model as string | undefined;
    if (!ref) continue;
    const t = textures(ref);
    const pick = (...keys: string[]) => keys.map((k) => resolve(t, k)).find((v) => v !== undefined);
    const top = pick("top", "end", "up", "all", "particle");
    const side = pick("side", "all", "north", "front", "particle", "top");
    if (!top && !side) continue;
    const tint = BIOME_TINT[id];
    out[`minecraft:${id}`] = [average(top ?? side!, tint), average(side ?? top!, id === "grass_block" ? undefined : tint)];
  }
  return out;
}

const memo = new Map<string, Promise<Record<string, [number, number]> | undefined>>();

/** The colour table for a Minecraft version: cached as JSON, built from the client jar the hub already has or downloads. */
export function blockColorsFor(home: string, mc: string, log: (m: string) => void = () => {}): Promise<Record<string, [number, number]> | undefined> {
  const key = `${home}|${mc}`;
  let p = memo.get(key);
  if (!p) {
    p = (async () => {
      const dir = join(home, "block-colors");
      const cache = join(dir, `${mc}.json`);
      if (existsSync(cache)) return JSON.parse(readFileSync(cache, "utf8")) as Record<string, [number, number]>;
      try {
        let jar = join(home, "client", "versions", mc, `${mc}.jar`);
        if (!existsSync(jar)) {
          mkdirSync(dir, { recursive: true });
          const v = await fetchVersion(mc, join(dir, "versions"));
          jar = join(dir, `${mc}.jar`);
          await fetchVerified({ ...v.downloads.client, dest: jar });
        }
        const table = extractBlockColors(jar);
        mkdirSync(dir, { recursive: true });
        writeFileSync(cache, JSON.stringify(table));
        return table;
      } catch (e) {
        log(`block colours for ${mc} unavailable (${e instanceof Error ? e.message : String(e)}); iso views use map colours`);
        memo.delete(key);
        return undefined;
      }
    })();
    memo.set(key, p);
  }
  return p;
}
```

package com.uxplima.craftwire.paper.it;

import static org.junit.jupiter.api.Assertions.*;
import com.google.gson.JsonObject;
import java.util.ArrayList;
import java.util.List;
import java.util.concurrent.CompletableFuture;
import org.junit.jupiter.api.Tag;
import org.junit.jupiter.api.Test;

@Tag("perf")
class BuildPerfIT {
    @Test
    void millionBlocksInTenSecondsWithoutLag() throws Exception {
        ItHub hub = ItEnv.get().hub;
        List<Double> tps = new ArrayList<>();
        long started = System.currentTimeMillis();
        CompletableFuture<JsonObject> run = CompletableFuture.supplyAsync(() -> {
            try {
                return hub.result("build.run", "{\"project\":\"perf\",\"origin\":{\"x\":8000,\"y\":-60,\"z\":8000},\"code\":\"fill(0,0,0,99,99,99,'stone')\",\"timeoutMs\":300000}").getAsJsonObject();
            } catch (Exception e) {
                throw new RuntimeException(e);
            }
        });
        while (!run.isDone()) {
            Thread.sleep(500);
            tps.add(hub.result("server.info", "{}").getAsJsonObject().get("tps").getAsJsonArray().get(0).getAsDouble());
        }
        long ms = System.currentTimeMillis() - started;
        JsonObject r = run.get();
        assertEquals(1_000_000, r.get("changed").getAsInt());
        System.out.println("[perf] 1M blocks in " + ms + " ms, tps samples " + tps);
        assertTrue(ms <= 10_000, "took " + ms + " ms");
        assertTrue(tps.stream().allMatch(t -> t >= 18.0), "tps " + tps);
        hub.result("build.manage", "{\"action\":\"clear\",\"project\":\"perf\"}");
    }
}
